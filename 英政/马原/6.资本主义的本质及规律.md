    2. 商品
        1. 使用价值即商品的有用性，是自然属性。社会财富=使用价值。不是商品也可以有使用价值，比如空气
            ![[Pasted image 20260920195307.png]]

        4. 使用价值和价值的关系：对立统一
            1. 不可兼得(对立)：每个人只能得到价值和使用价值中的一个
            2. 缺一不可(统一)：每个商品同时具有两种价值
    3. 生产商品的劳动二重性(Why商品有二因素)
        1. 具体劳动：导致使用价值产生。比如讲课、扫大街
        2. 抽象劳动(做题时等于价值)：导致价值产生。无非就是体力劳动和脑力劳动
        3. 任何一个劳动既是具体的，又是抽象的

3. 价值如何表现(通过交换)(学交换的历史)
    1. 简单偶然的：一只羊=两把斧子，用另一个商品的价值来表达本商品的价值，商品价值初级表达形式。
    2. 货币衡量：一只羊=1两黄金(货币)=两把斧子，用货币衡量价值，商品价值终极外化形式。商品世界=普通商品+货币(货币仅仅指贵金属)
    3. 价值尺度：货币可以衡量其他商品的价值的这种功能
        1. 斧子也有价值尺度
        2. 原因：因为货币本身也是商品，**具有价值**
        3. 货币是观念的货币(头脑的、想象的)，执行价值尺度功能(衡量价值)时不需要有真的货币(我看到一栋楼，知道它值一个亿，不需要自己身上真的有一个亿拿来比)
    4. 流通手段：货币可以充当商品交易的媒介
        1. 执行流通手段功能时必须是现实的货币(确实身上有)，有现货交易(一手交钱、一手交货)
        2. 货币流通时可以不足值：1两银子磕坏一点了，只要标的是1两，那就还是1两。从此衍生了纸币这种符号，纸币没有价值尺度功能，自身没有价值
    5. 支付手段：货币具有清偿、偿付、结算的功能
        1. 必须是现实的货币，没有现货交易(赊账)

# 资本主义经济制度：发达商品经济(资本主义及其之后的商品经济)

2. 劳动力成为商品(资本主义之后才成为商品)、货币转化为资本
    1. 劳动力是人劳动的能力，劳动是过程，劳动者是人本身。只有劳动力能成为商品
    2. 劳动力商品：价值(劳动者本人生活费用、家属生活费用、教育培训费用)；使用价值(劳动本身，可以创造新价值)
    3. 用钱买劳动力，钱叫资本(劳动力产生了更多价值，即增殖)；用钱买面包，钱叫货币(等价交换)
    ![[Pasted image 20260921090522.png]]
    ![[Pasted image 20260921090729.png]]
3. 剩余价值的生产
    ![[Pasted image 20260921091000.png]]
    ![[Pasted image 20260921091010.png]]
    ![[Pasted image 20260921094303.png]]
    ![[Pasted image 20260921094416.png]]
    1. 工人的价值不随着劳动时长增多而改变，资本家通过提升工人的劳动时长来获得剩余价值
    2. 从劳动角度看：工人的具体劳动创造最终商品的使用价值，并转移生产资料的价值到商品中去(面->包子)；抽象劳动创造新价值(包子-面)，新价值中有一部分为工人的工资，另一部分给资本家(新价值-工资，即m，剩余价值)
    3. 从资本角度看：80元买面，即购买生产资料的钱(不变资本c，平行转移不增殖)；20元买工人(会增殖，可变资本v)。剥削率(剩余价值率m')：m/v
    4. 从时间角度：前4个小时为自己劳动(产生工资)，是必要劳动时间，其中无剥削；后4个小时是剩余劳动时间，被资本家剥削。临界点就是生产出工资的点
    ![[Pasted image 20260921091310.png]]
    ![[Pasted image 20260921094210.png]]
    5. 绝对剩余价值、相对剩余价值、超额剩余价值
        1. 绝对剩余价值：加班，8个小时上升到12个小时，必要劳动时间没缩短，剩余劳动时间往后延长
        2. 相对剩余价值：8小时工作制，但是提高效率(技术进步)，导致2小时能完成工资(必要劳动时间缩短)，后6个小时全变成剩余劳动时间，剩余劳动时间往前延长
        3. 超额剩余价值：企业提高技术，会导致相对都提高

    ![[Pasted image 20260921094530.png]]
    ![[Pasted image 20260921094950.png]]

4. 资本积累
    ![[Pasted image 20260921095310.png]]
    1. 资本家用昨天从你身上赚的钱，来加大今天对你的剥削
    2. 资本积累的源泉是剩余价值，扩大再生产的源泉是资本积累
    ![[Pasted image 20260921095410.png]]
    ![[Pasted image 20260921095613.png]]
    ![[Pasted image 20260921095657.png]]
    3. 资本有机构成：就是价值构成，由技术构成决定。技术变导致价值变，则有机构成变；技术不变，价值自己变，则有机构成不变。要么变三个，要么只变一个
        1. 技术构成(物比物)：生产资料和劳动力的比例
        2. 价值构成(钱比钱)：不变资本比可变资本
        3. 资本家有钱之后，C变大，V变小
        ![[Pasted image 20260921100010.png]]
    4. 相对过剩人口
        1. 资本积累->有机构成提高->失业->两级分化->资本主义灭亡

5. 资本的循环周转(钱回到钱)与再生产
    1. 货币资本就是钱，商品资本就是你要卖的东西，其他都是生产资本。只有工人(劳动力)才是可变资本，劳动力是流动资本(一次劳动之后就需要休息)
    ![[Pasted image 20260921101938.png]]
    ![[Pasted image 20260921101945.png]]
    ![[Pasted image 20260921102016.png]]
    ![[Pasted image 20260921102856.png]]
    2. 固定资本：分多次转移到最终商品(盆，做完一次包子，盆还在)
    3. 流动资本：一次转移到最终商品(面)(做完一次包子，面没了)
    4. 价值补偿：东西卖出去，变回钱
    5. 实物补偿：生产完之后，不断引入原材料
    ![[Pasted image 20260921103039.png]]
    6. 社会再生产
        1. 前提假设
            1. 企业分两类：1生产生产资料的(造挖掘机)，2生产生活资料的(造衣服)。1c、1v、1m。2c、2v、2m
            2. 社会所有商品的总价值：C(总生产资料价值)+V(总工资)+M(总剩余价值)。
        2. 平衡条件：2c=1v+1m，其他都是自己内部交换，不需要和另一类企业交换。失衡到极致就经济危机
        ![[Pasted image 20260921103845.png]]
        3. 第一类企业要生成两类企业用的生产资料，第二类企业要生成供两个企业工人和资本家消费的产品
