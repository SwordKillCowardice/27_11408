# 1.结论
1. 变力沿直线做功
    ![[Pasted image 20260422140406.png]]
2. 抽水做功
    1. 抽取该微元柱体的水时，上方的水已抽走，故只需要考虑这部分柱体所受的重力
    2. 重力$F=mg=\rho gv$，进而确定微元$dF$
    ![[Pasted image 20260422140715.png]]
3. 静水压力
     1. 压强$p=\rho gh$，受力$P=pS$
    ![[Pasted image 20260422141114.png]]
4. 引力
    1. 取质量微元：$dm = \mu\,dx$
    2. 引力公式：$F = \frac{Gm_1m_2}{r^2}$
    ![[Pasted image 20260422141348.png]]
5. 质心、重心、形心
    1. 考研语境下，重心与质心始终重合。只有在密度为常数时，才有三心重合
    ![[Pasted image 20260422142452.png]]
6. **古鲁金定理**：快速求旋转体的表面积和体积
    1. $S$是旋转体的表面积、$V$是旋转体的体积
    2. 任何图形只要关于某一点中心对称，它的形心必然就是那个对称中心本身
    ![[Pasted image 20260422143311.png]]
    ![[Pasted image 20260422143538.png]]
