2. **洛必达法则**
    1. 若$lim_{x \to x_0}\frac{f(x)}{g(x)}$为$\frac{0}{0}\text{型或}\frac{\infty}{\infty}型$，**且$f(x)\text{与}g(x)$在$x_0$的去心邻域内可导($g'(x)\text{不恒为0}$)**，$lim_{x\to x_0}\frac{f'(x)}{g'(x)}$存在或为$\infty$，则$lim_{x\to x_0}\frac{f(x)}{g(x)}=lim_{x\to x_0}\frac{f'(x)}{g'(x)}$
    2. **补充**：只要分母极限是$\infty$就可以用洛必达；求单侧极限用洛必达时，只要求相应那一侧的去心邻域内可导，不需要两侧都可导
    3. 导数比的极限存在可以推出原式极限存在，反之不一定成立
        ![[Pasted image 20260219083938.png]]
    4. **不能使用洛必达法则的场景**：
        1. $f(x)\text{或}g(x)$仅在$x_0$可导
        2. 用完法则之后，发现比值极限不存在且非$\infty$，**此时应改用别的方法求解**
        3. 当$x\to 0$时，目标函数含有$sin\frac{1}{x}\text{或}cos\frac{1}{x}$因子；当$x\to \infty$时，目标函数含$sinx\text{或}cosx$因子。对这些因子求导，可能加剧振荡，而无法得到确定值
