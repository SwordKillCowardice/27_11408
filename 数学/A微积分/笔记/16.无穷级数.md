1. 级数的概念与性质
    1. 级数的定义
        1. $\sum_{n=1}^{\infty} u_n$只是一个记号，表示无穷项相加，记成这样不代表结果一定存在
        2. 常数项级数也简称数项级数
        ![[Pasted image 20260508102638.png]]
    2. 级数的敛散性
        1. 将级数的敛散性问题转化为求部分和数列的极限来研究
        2. 给出了判别级数敛散性的定义法：即求$lim_{n \to \infty}S_n$
        ![[Pasted image 20260508103845.png]]
    3. **级数的性质**
        1. 理解性质$2$(**使用非常频繁**)：改变**有限项**相当于对原来的收敛结果$S$施加了一个**确定**的影响$\Delta S$. 那么，如果原级数收敛，那么修改后的收敛结果变为$S+\Delta S$，依然收敛；原级数发散，修改后自然保持发散。**无穷问题，本质只看尾部**
        2. 性质$3$重要：注意逆否命题，注意反之不成立。有限项可以随意去括号，无限项不行
        ![[Pasted image 20260508105420.png]]
        3. 性质$4$反之不成立
        ![[Pasted image 20260508112150.png]]
        4. 性质$1$说明级数满足分配律，性质$3$说明级数满足加括号的结合律，但是级数不满足交换律
        ![[Pasted image 20260508110926.png]]

    2. **绝对收敛与条件收敛的性质**
        1. 若$\sum_{n=1}^{\infty}|u_n|$收敛，则$\sum_{n=1}^{\infty}u_n$必收敛(绝对收敛推原收敛)
        ![[Pasted image 20260508164326.png]]
        2. 挑出$u_n$中的所有正项$\sum_{n=1}^{\infty}v_n$和所有负项的绝对值$\sum_{n=1}^{\infty}w_n$. 则有：
            1. 若$\sum_{n=1}^{\infty}u_n$绝对收敛，则$\sum_{n=1}^{\infty}v_n和\sum_{n=1}^{\infty}w_n$都收敛
            2. 若$\sum_{n=1}^{\infty}u_n$条件收敛，则$\sum_{n=1}^{\infty}v_n和\sum_{n=1}^{\infty}w_n$都发散
            3. 证明不用那么麻烦，注只是为了提醒**条件收敛是正负项彼此抵消的结果**
            4. 当判别一个任意项级数的敛散性时，如果待判断项对原**条件收敛级数**做了改变正负的操作(**破坏正负抵消**)，那么新级数大概率不再收敛(培养直觉)
            5. 补充题目$5$：所有正项和所有负项的比值为$-1$
        ![[Pasted image 20260508164619.png]]
        ![[Pasted image 20260508165348.png]]

        ![[Pasted image 20260516100223.png]]
        ![[Pasted image 20260516100244.png]]
        3. 绝对收敛$\pm$绝对收敛=绝对收敛：三角不等式+比较判敛法
        4. 绝对收敛$\pm$条件收敛=条件收敛：反证法
        5. 条件收敛$\pm$条件收敛=两者都可能：记极端例子就行
        ![[Pasted image 20260508165608.png]]
