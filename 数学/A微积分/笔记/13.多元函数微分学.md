# 1.知识点
1. 邻域：**点的附近**，不包含边界
    ![[Pasted image 20260423153208.png]]
2. 极限：目标点附近的函数值都离极限值足够近
    ![[Pasted image 20260423153705.png]]
    1. 趋近目标点的方式有无穷多种
        ![[Pasted image 20260423153741.png]]
    2. 极限具有唯一性，从而可以取特殊趋近方式以否定极限存在
        ![[Pasted image 20260423153806.png]]
    3. **洛必达法则和单调有界准则只能对单变量使用**，求多元极限时失效。其他方法可以用，比如夹逼准则、等价无穷小代换、脱帽法等 #高数三轮 
3. 连续：极限值等于函数值。二元初等函数在定义区域上是连续的
    ![[Pasted image 20260423154729.png]]
4. 偏导数
    1. 基本理解：研究一元导数时变化方向仅在$x$轴上，只有$x$的增大缩小两种方向；而研究多元导数时变化方向有无穷多种，称为方向导数。偏导数是方向导数的特例
        ![[Pasted image 20260423160020.png]]
    2. 定义：增量式+函数式
        ![[Pasted image 20260423160133.png]]
        ![[Pasted image 20260423160840.png]]
    3. 几何直观：切平面上的曲线对轴的斜率
        ![[Pasted image 20260423160253.png]]
        ![[Pasted image 20260423160208.png]]
    4. 偏导函数：类比导函数
        ![[Pasted image 20260423160227.png]]
    5. 结论：区域$D$上两个偏导数都恒为$0$的话，$f(x,y)$为常数 #高数三轮 
        1. **注意**：其中一个偏导数恒为$0$，不能认为$f(x,y)$退化为单变量函数
