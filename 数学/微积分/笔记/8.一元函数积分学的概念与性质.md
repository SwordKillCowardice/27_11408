# 2.结论
1. 导函数$f'(x)$的性质\[对比一般函数$f(x)$\]
    1. $f(x_0)$存在且该点极限存在，无法推出$f(x)$在$x_0$连续；而$f'(x_0)$存在且该点极限存在，可以推出$f'(x)$在$x_0$连续(洛必达)
        ![[Pasted image 20260325194451.png]]
    2. $f(x)$存在且连续才具有介值性；而$f'(x)$存在就必有介值性(达布定理)
        ![[Pasted image 20260325194816.png]]
    3. 若$f'(x)$存在，则$f'(x)$一定没有第一类间断点：否则在包含间断点的小区间内不满足达布定理
        ![[Pasted image 20260325195048.png]]
    4. 在一条处处有切线的曲线上，不会发生切线斜率突变
    5. 若$f(x)$可导，则$f'(x)$可能连续，也可能含有振荡间断点(见后面原函数存在定理)
2. **原函数存在定理**：连续性与原函数存在性
    1. 连续函数$f(x)$必有原函数$F(x)$：$F(x)$为变上限积分函数
        ![[Pasted image 20260325193629.png]]
        ![[Pasted image 20260325193739.png]]
    2. 含有一类间断点和无穷间断点的函数$f(x)$在包含该间断点的区间内必然没有原函数
        ![[Pasted image 20260325195640.png]]
        ![[Pasted image 20260325195654.png]]
    3. 含有振荡间断点的函数$f(x)$可能有原函数
        ![[Pasted image 20260325195841.png]]
    4. 总结
        ![[Pasted image 20260325195901.png]]
3. 定积分存在(可积)定理：四充分+两必要
    1. 核心：**区间有限、函数有界**
    2. 充分条件：已给定有限区间，本质就是限定$f(x)$有界
        ![[Pasted image 20260325214505.png]]
        ![[Pasted image 20260325214521.png]]
    3. 必要条件：此处需与后面的反常积分加以区分
        ![[Pasted image 20260325214733.png]]

7. **判别反常积分的敛散性**：不等式放缩、比值极限、重要结论
    1. **收敛本质**：靠轴近(底无限大，高必须足够小)。对于无穷区间积分，$f(x)$靠近$0$足够快；对于无界函数积分，$f(x)$靠近无穷足够慢
        ![[Pasted image 20260327113146.png]]
    2. 无穷区间判敛散：使用不等式时注意左边$>=0$
        ![[Pasted image 20260327140118.png]]
    3. 无界函数判敛散：同上
        ![[Pasted image 20260327140135.png]]
    4. **结论**
        1. $\frac{1}{x^p}$敛散性
            ![[Pasted image 20260327140219.png]]
            1. 在$(0,1)$和$(1,+\infty)$正好相反。$(0,1)$上越小越收敛，$(1,+\infty)$上越大越收敛
            2. $p=1$为临界情况，必发散
            3. $p>0$为了保证在分母
        2. 推广
            ![[Pasted image 20260327140712.png]]
            ![[Pasted image 20260327140723.png]]
        3. $|f(x)|$积分收敛，则$f(x)$积分也收敛
            ![[Pasted image 20260327134245.png]]
        4. 若$f(x)$在$(0,1)$上单调，且反常积分$\int_{0}^{1}f(x)dx$收敛，则可用等距取样的黎曼和逼近该积分
            ![[Pasted image 20260327220803.png]]
    5. 方法总结：**直接按反常积分的定义算积分的值也是一个方法**
        ![[Pasted image 20260327122408.png]]
