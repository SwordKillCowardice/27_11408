# 1.知识点
1. 数列一定有无穷多项
2. 子列：从原数列中选取无穷多项，并保持他们在原数列中的先后顺序
3. **有界数列**：若存在一个正实数$M$，对任意正整数$n$，都有$|a_n|<=M$，则称$\{a_n\}$为有界数列
4. 收敛速度：用于判定数列极限定义题。数列极限定义本身不体现速度，**故要求$\varepsilon$和$n$没有任何关系**

# 2.结论
1. **有限项**中一定既有最大值又有最小值
2. **压缩映射原理**：同构、找到$0-1\text{之间的}k$
    ![[Pasted image 20260304145713.png]]
3. **收敛数列的性质**
    1. 数列收敛与其子列收敛的关系
        ![[Pasted image 20260304110001.png]]
        1. 难以穷举所有子列来验证原数列收敛，所以该定理通常**逆用于反证原数列发散：寻找发散的子列，或者收敛到不同极限的子列，如$\{(-1)^n\}$
        2. 某个子列收敛，并不能保证原数列收敛
    2. 唯一性、有界性(整个数列都有界)、保号性(戴帽加等号，取$\frac{1}{n}$为例)
        ![[Pasted image 20260304115511.png]]
4. **海涅定理(归结原则)**：沟通数列极限和函数极限
    ![[Pasted image 20260304121904.png]]
    1. 函数极限$f(x)$是针对连续区间的，可以离散化用于推导数列极限$f(x_n)$
    2. 数列极限$f(x_n)$是针对离散点集的，可以用不同的数列极限来推导函数极限$f(x)$不存在
    3. 常用转化
        ![[Pasted image 20260304122225.png]]
5. **夹逼准则**：前面的有限项不在意，两边的等号不在意
    ![[Pasted image 20260304143021.png]]
6. **单调有界准则**：单调指的不是严格单调，而是单调不增(减)；前面有限项不单调也没关系，不会影响极限
