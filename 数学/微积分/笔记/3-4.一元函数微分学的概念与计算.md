# 2.结论
1. $f(x)$在点$x_0$可导的充要条件：左右导数(单侧导数)存在且相等
    ![[Pasted image 20260306185602.png]]
2. $f(x)$在点$x_0$可导，则在$x_0$必连续。反之不成立(反例：$|x|$在$x=0$处)
    ![[Pasted image 20260306190021.png]]
    1. 可以结合导数定义的函数式，从收敛速度来理解：连续时仅仅要求分子趋于0，但**可导要求**分子趋于0的**速度不低于分母**。故无法由连续推导出可导
    2. 某一点可导只能推导出该点连续，连附近点的连续性都保证不了，更谈不上推出附近的点可导
    3. 推广到高阶导数
        ![[Pasted image 20260306205429.png]]

    2. 可导的微观理解
        $f(x_0)=0\text{且在}x_0\text{处可导时}$： #高数一轮 #混淆 
        1. $f'(x_0)\neq 0$时，加绝对值之后必然导致左右导数不相等，故$|f(x)|在x_0$处不可导
        2. $f'(x_0)=0$时：函数式中分子(即$f(x)$)的收敛速度远大于分母，此时$|f(x)|在x_0$处收敛速度(分子$|f(x)|$)依然保持远大于分母，故必定可导，且导数值为0

        ![[Pasted image 20260306203138.png]]
4. $f(x)在点x_0$处切线存在与导数存在的关系
    ![[Pasted image 20260306204117.png]]
    1. 导数存在切线必定存在
    2. 导数不存在分两种情况：无穷导数、左右导数存在且不相等
    3. 导数不存在但为无穷导数时，切线存在。$y=x^ \frac{1}{3}在x=0$处切线为$x=0$(可以结合$y=x^3$来理解，$y=x^3在x=0处切线为y=0$，而这两个函数互为反函数)
    4. 导数不存在，而且是由于左右导数存在且不等时，切线不存在。$y=|x|$
