# 1.知识点
1. 极限的本质：**类型 + 变化趋势**
    1. 类型：$n \to \infty$ 、$x \to x_0$ 、$x \to \infty$
    2. 趋势：稳定型(极限值存在)、无界型(趋于无穷大)、振荡型(区间内振荡、无穷振荡)、不等型(左极限不等于右极限)
2. 函数极限
    1. 定义(趋于有限值)：设函数$f(x)$在点$x_0$的某去心邻域内有定义。如果存在常数$A$，使得：$\forall \varepsilon > 0, \exists \delta > 0,  \text{使得 } 0 < |x-x_0| < \delta \implies |f(x)-A| < \varepsilon$，则称$lim_{x \to x_0} f(x) = A$
    2. 类型：趋于$x_0 、\infty$，以及各自的左右：${x_0}^+、+\infty$
3. 无穷大量和无穷小量
    1. 定义：对于给定数列或函数，在某个变化过程中，值趋于$\infty$则称为无穷大量；值趋于0则称为无穷小量
    2. $\infty$不是数，只是一个记号。**$\infty$代表极限不存在，但极限不存在不一定是$\infty$**
    3. **性质**：无穷大量、无穷小量、有界量
        1. 无穷小 x 有界 = 无穷小，如$lim_{x \to 0}x\sin{\frac{1}{x}} = 0$
        2. 无穷大 x 有界 = 不确定，如$lim_{x\to 0}\frac {1}{x}\cdot \sin {\frac{1}{x}}$ #高数一轮  #混淆
        3. 无穷小 + 无穷小 = 无穷小(**有限个**) #高数一轮  #卡顿 
            ![[Pasted image 20260218154044.png]]
        4. 无穷大 + 无穷大 = 不确定
        5. 无穷小 x 无穷小 = 无穷小(有限个)
        6. 无穷大 x 无穷大 = 无穷大
    4. **无穷小的阶**：设$f(x)，g(x)$为某变化过程的无穷小，定义比值$r=\frac{f(x)}{g(x)}$
        1. 若对于该变化过程，$r = 1$ 。则称$f(x)\text{与}g(x)$为等价无穷小，记作$f(x)\sim g(x)$
        2. 若$r = C(\text{非零常数})$，则称$f(x)\text{与}g(x)$为同阶无穷小，有$f(x) \sim C\cdot g(x)$
        3. 若$r = 0$，则称$f(x)\text{为}g(x)$的高阶无穷小，记作$f(x)=o(g(x))$
        4. 若$r = \infty$，则称$f(x)\text{为}g(x)$的低阶无穷小，此时$g(x) = o(f(x))$
        5. $k$阶无穷小
            ![[Pasted image 20260218155059.png]]
        6. **并不是任意两个无穷小都可以比阶**，因为比值极限可能为震荡发散
            ![[Pasted image 20260218155232.png]]
4. 泰勒公式
    1. 泰勒公式：**拉格朗日余项**要求$x_0$的**邻域内**$n+1$阶存在；而佩亚诺余项只要求$x_0$处$n$阶存在 #高数一轮 #卡顿 
        ![[Pasted image 20260323194123.png]]
    2. **幂函数是所有可导函数的一个基**
        ![[Pasted image 20260219095514.png]]
    3. 等价无穷小替换的本质是泰勒展开：$f(x) = \text{主导项} + o(\text{主导项})$
        1. 比值可以直接替换：$\frac{f(x)}{g(x)} = \frac{\beta + o(\beta)}{\beta} = 1 + \frac{o(\beta)}{\beta} \to 1$
        2. 加减不能直接替换：$f(x) - g(x) = (\beta + o(\beta)) - \beta = o(\beta)$
        3. 原因：**加减过程中产生的高阶无穷小无法忽略**
    4. 使用泰勒公式求极限：**上下同阶、展开到无法抵消的最低幂为止**
    5. **复合函数的泰勒展开**：先展开外层函数，再将展开式中的变量换成实际的中间变量
        ![[Pasted image 20260219090255.png]]
5. 连续：内点要求极限存在且等于函数值，左端点要求右极限存在且等于函数值，右端点要求左极限存在且等于函数值
    1. 基本初等函数(反对幂指三)，以及由它们通过有限次四则运算和复合运算得到的函数，在其定义域内都是连续的
    2. 连续性运算法则：四则运算、复合、反函数
        ![[Pasted image 20260219163801.png]]
    3. 函数$f(x)$在某一点$x_0$连续，但在$x_0$附近不一定连续
        1. 反例：$f(x)在x=0$处连续\[无穷小X有界量，$f(x)=x^2\cdot D(x)$\]，但$x\neq 0$时一定不连续(用海涅定理，取有理数列和无理数列)
            ![[Pasted image 20260304123758.png]]
        2. 狄利克雷函数：**在每一点都不连续**
            ![[Pasted image 20260304123745.png]]
6. 间断：要求函数在目标点附近(两侧)有定义(**所以区间端点不考虑间断**)，对目标点定义与否不做要求
    1. **间断点是横坐标**
    2. 第一类间断点：左、右极限均存在。若左极限等于右极限且不等于函数值，为可去(可补)间断点；左极限不等于右极限，为跳跃间断点
    3. 第二类间断点：左、右极限中至少有一个为无穷，则无穷间断点；左、右极限中至少有一个为振荡，则振荡间断点
    4. **间断点存在的位置：函数无定义的点(必定间断)、分段函数分段点(不一定间断)**
    5. 本期嘉宾：$\frac{1}{tanx}(x=\frac{k\pi}{2}\text{均不能取})$
