# 2.习题
1. 三角函数型
    1. **核心理解**：$sinx、cscx、tanx$分别与$cosx、secx、cotx$**高度对称**，这意味着他们复合而成的函数是**高度可交换**的，**求解思路也可以迁移**
    2. 题型一：$sin^mx\cdot cos^nx$型 ($m>=1$)
        1. **对称性**：该题型的思路可以直接迁移到$cos^mx\cdot sin^nx$型 ($m>=1$)
        2. $m\text{为}奇数$：凑$dcosx$，本质是幂函数
            1. $m=1$：直接凑
                ![[Pasted image 20260208075941.png]]
                ![[Pasted image 20260215112910.png]]
            2. $m>=3$：拿一个凑$dcosx$，剩下的写成$(1-cos^2x)^{\frac{m-1}{2}}$
                ![[Pasted image 20260208082610.png]]
                ![[Pasted image 20260208083611.png]]
                ![[Pasted image 20260215113012.png]]
        3. $m=2$：$sin^2x$变形为$1-cos^2x$，本质是$cos^nx-cos^{n+2}x$
            ![[Pasted image 20260208081418.png]]
            ![[Pasted image 20260208083739.png]]
    3. 题型二：$\frac{1}{sin^mx\cdot cos^nx}$型 ($m>=1\text{且}n>=1$)
        1. **通用思路**：利用$sin^2x+cos^2x=1$反复分解降幂
        2. $m\neq n$：使用分解降幂法
            ![[Pasted image 20260209072812.png]]
        3. $m=n$：优先使用$sinxcosx=\frac{sin2x}{2}$对分母进行变形，转化为求$csc^mx$ ; 也可以使用分解降幂法
            ![[Pasted image 20260209073115.png]]
    4. 题型三：$sec^nx$型
        1. $n=1$：分子分母同乘$(secx+tanx)$，然后凑微分
        2. $n$为奇数$(n>1)$：取一个$sec^2x$凑成$dtanx$，然后分部积分。分部积分后利用$tan^2x=sec^2x-1$进行变形，找到循环和递推
            ![[Pasted image 20260406143757.png]]
        3. $n$为偶数：取一个$sec^2x$凑成$dtanx$，然后用$sec^2x=tan^2x+1$转化为幂函数积分
            ![[Pasted image 20260406143925.png]]
    5. 题型四：$tan^nx$型
        1. **通用思路**：取一个$tan^2x$写成$sec^2x-1$，发现$tan^nx$和$tan^{n-2}x$有关
        2. $n=1$：直接凑微分
        3. $n>1$：使用通用思路
