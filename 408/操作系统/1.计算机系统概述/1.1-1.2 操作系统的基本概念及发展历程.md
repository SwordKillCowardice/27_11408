2. 操作系统的功能和目标
    1. 作为系统资源的管理者：处理机管理、存储器管理、文件管理、设备管理
        1. **处理机管理本质是对进程的管理**：处理机的分配和运行以进(线)程为基本单位
        2. 存储器管理：**为多道程序提供良好的内存运行环境**，方便用户使用并提高内存利用率
        3. 设备管理：处理用户的**I/O**请求，屏蔽设备差异
        4. 实例：Step1-4分别对应文件管理、存储器管理(运行前要把程序装入内存)、处理机管理、设备管理(用摄像头)
            ![[Pasted image 20260611131606.png]]
        5. 操作系统通过管理**软件运行所依赖的系统资源**间接管理软件的执行
    2. 作为用户与计算机硬件系统之间的接口
        1. 图示：用户通过**应用程序或直接交互方式**访问系统服务
            ![[Pasted image 20260611132907.png]]
        2. 用户接口：包含命令方式和图形方式，面向普通终端用户
            1. 图形化用户接口(GUI)：降低使用门槛
            2. 联机用户接口(命令行接口)：实时交互场景。用户说一句，系统做一句
            3. 脱机用户接口(作业控制语言)：批处理系统。用户说一堆，系统做一堆
        3. 程序接口：**由系统调用组成**，面向应用程序设计/程序员，**普通用户**通过程序代码**间接使用**。是应用程序在运行时**请求操作系统服务、访问系统资源**的唯一合法途径
        4. 库函数界定：**库函数不是程序接口**。部分库函数封装了系统调用，而部分库函数则完全不涉及系统调用
    3. 实现了对计算机资源的扩充(对硬件机器的拓展)
        ![[Pasted image 20260611135921.png]]
3. 操作系统的特征
    1. 并发性：计算机系统中"同时"运行着多个程序(多道程序系统)。这些程序宏观上同时运行，微观上交替运行。**操作系统和程序并发是一起诞生的**
        1. 并发VS并行
            ![[Pasted image 20260611145105.png]]
        2. 单核CPU VS 多核CPU
            ![[Pasted image 20260611150204.png]]
        3. 只有单处理机+单核CPU的组合不能并行，其他都可以
            ![[Pasted image 20260611150618.png]]
        4. CPU与I/O设备之间、多个I/O设备之间可以并行
            ![[Pasted image 20260611151221.png]]
    2. 共享性(资源共享)：系统中的资源可供内存中多个并发执行的进程共同使用
        ![[Pasted image 20260611151643.png]]
        ![[Pasted image 20260611152512.png]]
        ![[Pasted image 20260715150338.png]]
        1. 只能互斥共享的资源称为临界资源，如打印机、共享变量
        2. 同时共享微观上仍然是并发共享(两个进程交替读只读文件)
        3. 重入代码的代码段属于可同时访问资源
            ![[Pasted image 20260611153327.png]]
    3. 虚拟性：将一个物理实体(实际存在的)映射为多个逻辑上的对应物(用户感受到的)
        1. OS主要通过**时分复用**(如处理器分时)和**空分复用**(如虚拟存储器)实现虚拟
            ![[Pasted image 20260611154521.png]]
            ![[Pasted image 20260611154350.png]]
        2. 通过**虚拟设备技术**(如SPOOLing)，可将某些独占型物理I/O设备(如打印机)化为多台逻辑设备，以实现共享
        3. 没有并发性，就谈不上虚拟性(只运行单个进程，实际内存和单个CPU就够用)
    4. 异步性：在多道程序环境下，多个进程并发执行，但由于系统资源有限，进程的执行并非连续进行，**而是以不可预知的速度断续推进**。只有系统拥有并发性，才可能导致异步性。
    5. **并发与共享是操作系统两个最基本的特征，二者互为前提**
        ![[Pasted image 20260611153915.png]]
4. 操作系统发展历程
    1. 图示
        ![[Pasted image 20260612090900.png]]
    2. 手工操作阶段(未配置操作系统)
        1. 人工操作方式：共五个阶段
            ![[Pasted image 20260611201245.png]]
            1. 值得注意的是：**装、取纸带时也需要独占计算机**
            2. 完成一个作业的时间示意图
                1. 用户独占全机，一台计算机只服务一个用户的一个作业(多道批处理出现之前都是)，系统资源利用率极低
                2. 人工装取纸带时间长，CPU空等太久，人机速度矛盾突出
                ![[Pasted image 20260611200158.png]]
        2. 脱机I/O方式：共三个阶段
            ![[Pasted image 20260611202444.png]]
            1. 脱机IO VS 联机IO：看主机是否需要直接管理I/O设备。联机I/O时CPU需要全程参与控制传输
                ![[Pasted image 20260611203605.png]]
            2. 采用脱机I/O(外围机+磁带)：把**慢速纸带机的联机I/O**转嫁给外围机，主机只保留**高速磁带的联机I/O**
                1. 输入时，外围机负责将纸带上的程序和数据读入磁带
                2. 输出时，外围机负责将CPU写的磁带内容输出至外设
                3. 人工装取纸带的时间消耗也转嫁给了外围机
                ![[Pasted image 20260611202709.png]]
            3. 主机不再参与装带、取带操作，显著减少了CPU空闲时间。直接从高速磁带读写，大幅提升了I/O效率
    3. 批处理阶段(操作系统开始出现)
        1. 单道批处理系统：使用脱机I/O技术，一次输入一批作业到磁带。由**监督程序**(操作系统的雏形)负责控制作业自动、按序地逐个运行。
            1. 主要特征
                ![[Pasted image 20260611210015.png]]
            2. 执行时序图：内存中仅支持一道作业运行。CPU与I/O无法并行，无法在J1执行计算时，从磁带输入J2
                ![[Pasted image 20260611205224.png]]
            3. 优缺点
                ![[Pasted image 20260611205723.png]]
        2. 多道批处理系统(操作系统正式诞生)：使用**作业调度程序**，一次选取若干作业调入内存。作业请求I/O时，会主动交出CPU，OS通过调度程序把CPU给下一个作业。I/O完成后，通过**中断**通知OS，原作业重新进入就绪队列
            1. 主要特征
                ![[Pasted image 20260611213436.png]]
            2. 执行时序图：可以往内存中读入多道程序。CPU与I/O可以并行，在J1执行计算时可以读入J2，J1输出时J2可以执行计算
                ![[Pasted image 20260611210318.png]]
            3. 优缺点
                ![[Pasted image 20260611213416.png]]
    4. 分时操作系统：以人机交互为核心目标
        ![[Pasted image 20260612083729.png]]
        ![[Pasted image 20260612083942.png]]
    5. 实时操作系统：**在严格的时间限制内完成关键任务**。采用基于任务紧迫性或截止时间的调度策略，为了保证快速处理高优先级任务，允许“浪费”一些系统资源
        ![[Pasted image 20260612084633.png]]
        ![[Pasted image 20260612084658.png]]
        ![[Pasted image 20260612084525.png]]
        ![[Pasted image 20260612084533.png]]
    6. 其他操作系统(了解)
        1. 网络操作系统：单机操作系统(运行在一台独立计算机上，主要负责管理该计算机自身资源的操作系统)+网络功能
            1. 各计算机彼此独立，通过网络共享资源
            ![[Pasted image 20260612085304.png]]
        2. 分布式操作系统：用于管理分布式系统，具有分布性、并行性、透明性
            ![[Pasted image 20260612090000.png]]
            ![[Pasted image 20260612090147.png]]
        3. 微机操作系统：为微型计算机(如个人电脑)设计的操作系统。按用户数和并发能力分类如下：
            1. 单用户单任务OS：仅允许一个用户登录并运行一个程序
            2. 单用户多任务OS：支持一个用户同时运行多个程序(时间片轮转)
            3. 多用户多任务OS：允许多用户并发执行多个任务，资源共享且互不干扰
