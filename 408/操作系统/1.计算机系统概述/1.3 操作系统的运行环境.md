# 1.知识点
1. 程序的运行
    1. 高级语言需要通过**编译或解释**的方式转化为机器指令后由CPU执行，程序运行的过程就是CPU执行一条条机器指令的过程
    2. 一条高级语言代码可能对应多条机器指令，指令是CPU能识别并执行的最基本命令
    ![[Pasted image 20260612140904.png]]
2. 处理机的双重工作模式(三组对比)
    1. 为确保操作系统正确运行，必须严格区分操作系统代码与用户程序的执行环境。通过为处理机设置两种运行模式(用户态和内核态)，并使用一个**模式位**来标识当前运行模式，以实现区分
    2. 应用程序 VS 内核程序
        ![[Pasted image 20260612143759.png]]
    3. 特权指令 VS 非特权指令
        1. 可能危及系统安全的指令定义为特权指令，仅允许在内核态下执行
        2. 其余指令定义为非特权指令，可在任意模式下执行
        3. 在CPU设计和生产的时候就划分了特权指令和非特权指令，因此CPU执行一条指令前就能判断出其类型
        ![[Pasted image 20260612150807.png]]

3. 中断(外中断)和异常(内中断)
    1. 中断或异常是**用户程序进入内核态**的唯一合法途径，也是**操作系统内核夺回CPU使用权**的唯一途径
    2. 中断的定义与分类
        1. 陷入指令是非特权指令，常用于程序主动请求OS服务，使用后引发异常。系统调用就是通过陷入指令完成的
        2. 异常一旦发生，就必须立即处理，不能屏蔽
        3. 每一条指令执行结束时，CPU都会例行检查是否有外中断信号
        4. 故障和自陷异常属于软件中断(程序性异常)，终止异常和外中断属于硬件中断

4. 系统调用
    1. 定义：系统调用是操作系统提供给应用程序(程序员)使用的接口，每个系统调用有唯一的系统调用号
    2. 系统调用的必要性
        1. **应用程序通过系统调用来请求操作系统服务，使用共享资源**
        2. 如果没有系统调用，任由各程序随意使用共享资源，则可能出现混乱
        ![[Pasted image 20260612165631.png]]
    3. 系统调用的分类
        ![[Pasted image 20260612165113.png]]
    4. 区分系统调用与普通过程调用
        ![[Pasted image 20260612165901.png]]
    5. 系统调用的处理过程(4个阶段)
        ![[Pasted image 20260612170817.png]]
        1. 执行传参指令，将系统调用参数传入寄存器或堆栈
        2. 执行陷入指令(在用户态执行)，引发内中断，切换至内核态
        3. 内核根据相关参数定位所需的系统调用服务，进行中断处理(内核态下)
        4. 处理完毕后返回用户态，继续执行应用程序
