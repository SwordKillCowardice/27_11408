# 1.知识点
1. 程序的运行
    1. 高级语言需要通过**编译或解释**的方式转化为机器指令后由CPU执行，程序运行的过程就是CPU执行一条条机器指令的过程
    2. 一条高级语言代码可能对应多条机器指令，指令是CPU能识别并执行的最基本命令
    ![[Pasted image 20260612140904.png]]
2. 处理机的双重工作模式(三组对比)
    1. 为确保操作系统正确运行，必须严格区分操作系统代码与用户程序的执行环境。通过为处理机设置两种运行模式(用户态和内核态)，并使用一个**模式位**来标识当前运行模式，以实现区分

    3. 特权指令 VS 非特权指令
        1. 可能危及系统安全的指令定义为特权指令，仅允许在内核态下执行
        2. 其余指令定义为非特权指令，可在任意模式下执行
        3. 在CPU设计和生产的时候就划分了特权指令和非特权指令，因此CPU执行一条指令前就能判断出其类型

3. 中断(外中断)和异常(内中断)
    1. 基本概念
        1. 异常是指CPU在执行指令过程中，其内部检测到的同步事件，**与当前指令有关**
        2. 中断是由外部设备发起(通过中断请求信号线)的异步事件，用于通知CPU外设状态发生变化，**与当前指令无关**
        3. 中断或异常是**用户程序进入内核态**的唯一合法途径，也是**操作系统内核夺回CPU使用权**的唯一途径
    2. 异常和中断的分类
        1. 异常可分为硬故障中断(硬件逻辑功能异常)和程序性异常(软件中断)(指令执行异常)
            1. 对于可恢复的故障(缺页)，OS处理完成之后重新执行该指令；而对于不可恢复的故障(除0)，通常引发进程终止
            2. 自陷处理完毕后，OS执行下一条指令
            3. 终止：指令执行过程中发生严重的硬件故障，程序被迫终止
            4. 异常一旦发生，就必须立即处理，不能屏蔽
        2. 中断分为可屏蔽中断和不可屏蔽中断
            1. 可屏蔽中断：通过可屏蔽中断请求线**INTR**发送，CPU可通过中断控制器中的中断屏蔽寄存器选择性地屏蔽特定中断源
            2. 不可屏蔽中断：通过不可屏蔽中断请求线**NMI**发送，无法被软件屏蔽
            ![[Pasted image 20260821152337.png]]
        3. 故障和自陷异常属于程序性异常，终止异常和外中断属于硬件中断
        4. 陷入指令(访管指令)是非特权指令，常用于程序主动请求OS服务，使用后引发异常。系统调用就是通过陷入指令完成的
        5. 每一条指令执行结束时，CPU都会例行检查是否有外中断信号

4. 系统调用
    1. 定义：系统调用是操作系统提供给应用程序(程序员)使用的接口，每个系统调用有唯一的系统调用号
    2. 系统调用的必要性
        1. **应用程序通过系统调用来请求操作系统服务，使用共享资源**
        2. 如果没有系统调用，任由各程序随意使用共享资源，则可能出现混乱
        ![[Pasted image 20260612165631.png]]
    3. 系统调用的分类

    5. 系统调用的处理过程(4个阶段)
        ![[Pasted image 20260612170817.png]]
        1. 执行传参指令，将系统调用参数传入寄存器或堆栈
        2. 执行陷入指令(在用户态执行)，引发内中断，切换至内核态
        3. 内核根据相关参数定位所需的系统调用服务，进行中断处理(内核态下)
        4. 处理完毕后返回用户态，继续执行应用程序
