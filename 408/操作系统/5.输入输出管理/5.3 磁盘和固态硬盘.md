# 1.知识点
1. 磁盘的基本概念
    1. 磁盘的定义及结构
        1. **磁盘是由**表面涂有磁性物质(磁性物质可以记录二进制数据)的**盘片构成**的存储设备，通过磁头读写数据。读写期间，**盘片高速旋转**，磁头负责定位目标位置
        2. 磁记录原理：利用电磁感应(磁性方向和电流方向)
            ![[Pasted image 20260802095215.png]]
        3. 盘片(记录面)的构造
            1. 盘面上的数据存储在一组同心圆中，每个同心圆称为一个磁道。一个盘面包含上千个磁道
            2. 每个磁道划分为数百个扇区，每个**扇区**大小固定且相同，一个扇区就是一个磁盘块。扇区**是磁盘寻址的最小单位**，即**磁盘的最小读写单位**
            3. 相邻磁道及扇区间留有空隙，避免读写时彼此干扰
            4. 由于每个磁道扇区数相同，而**外道周长更大**，故**线性存储密度低于内道**(内外存的数据一样多，但是外道空间大)。磁盘的存储能力受限于最内圈的最大记录密度
            5. 一个盘片可能有上下两个盘面
            ![[Pasted image 20260715213805.png]]
        4. 磁盘的结构
            1. 磁盘驱动器由磁头臂、驱动盘片旋转的转轴以及数据输入输出电路组成
            2. 每个盘面(记录面)对应一个磁头，所有磁头安装在同一磁头臂上，同步径向移动(同进退)
            3. 所有盘片上半径相同的磁道构成一个柱面(即上下同一位置的磁道)，因而柱面数=磁道数
            4. 总存储容量由柱面数、盘面数和每磁道扇区数共同决定
            ![[Pasted image 20260802094558.png]]
            ![[Pasted image 20260715214243.png]]
    2. 磁盘的读写过程(三步)
        1. 根据柱面号移动磁头臂，使磁头定位到目标柱面(定位磁道)
        2. 激活对应盘面的磁头
        3. 等待目标扇区旋转到磁头下方，完成读写
        4. 磁盘按**批处理方式**进行一个数据块的读/写，串行执行
        5. 某一时刻永远只能读/写一个磁道，不能同时读一整个柱面
        6. 扇区**是磁盘寻址的最小单位**，即**磁盘的最小读写单位**
        ![[Pasted image 20260802101102.png]]
        ![[Pasted image 20260802105059.png]]
    3. 磁盘高速缓存(回忆页缓冲队列)
        ![[Pasted image 20260802095102.png]]
    4. 磁盘的性能指标
        1. 磁盘容量
            1. 非格式化容量=记录面数X每面磁道数X每磁道中磁化单元数
            2. 格式化容量=记录面数X每面磁道数X每磁道扇区数X每扇区字节数
            3. **非格式化容量大于格式化容量**
            ![[Pasted image 20260802095823.png]]
        2. 记录密度
            ![[Pasted image 20260802100139.png]]
        3. 响应时间与存取时间
            1. 响应时间=排队延迟+控制器时间+(平均)存取时间
            2. (平均)寻道时间=最大寻道(最外道->最内道)时间的一半
            ![[Pasted image 20260802100403.png]]
        4. 数据传输速率(注意单位是字节)
            ![[Pasted image 20260802100633.png]]
    5. 磁盘存储器的优缺点
        ![[Pasted image 20260802094130.png]] 
    6. 磁盘的分类
        1. 按磁头能否移动
            1. 固定头磁盘：磁头位置固定，每个磁道一个磁头，每个盘面多个磁头
            2. 活动头磁盘：磁头可沿着径向移动，每个盘面一个磁头
        2. 按盘片能否更换
            1. 固定盘磁盘：盘片不可更换
            2. 可换盘磁盘：盘片可以更换
    7. 最早的磁盘叫温彻斯特磁盘(温盘)，活动磁头加固定盘片，是现代机械硬盘的雏形
2. 磁盘的管理
    1. 磁盘初始化(三步)
        1. 低级初始化通常在磁盘出厂时就已经完成
        2. 头尾部中包含了一些**磁盘控制器的使用信息**，如利用磁道号、磁头号和扇区号来标识一个扇区，扇区校验等
        3. 每个分区的起始位置和大小记录在主引导记录(MBR)的分区表中
        4. 逻辑格式化即为高级格式化，在分区上建立文件系统
        5. OS通常将多个连续扇区合成一簇(文件系统中的块)，并按簇给单个文件分配空间，故文件占用空间为簇的整数倍
        6. 操作系统的安装在逻辑格式化之后
        ![[Pasted image 20260715220700.png]]
    2. 引导块
        1. 计算机开机时需要进行一系列的初始化工作，并启动OS。这些工作通过执行**初始化程序(自举程序)完成**
        2. 自举程序通常储存在ROM中，由于ROM中程序无法修改，故仅在ROM中保留一个小型**自举装入程序**，而将**功能完整的引导程序**放入磁盘的**引导块(启动块、启动分区)中**
        3. 引导块位于磁盘的固定位置，**含有引导块的磁盘称为启动磁盘(系统磁盘)**
    3. 坏块
        1. 磁盘容易出现一个或多个扇区(即磁盘块)损坏，这些称为坏块
        2. 坏块的处理思想：通过软件标记或硬件重映射，避免系统使用坏块
            1. 简单磁盘(如采用IDE控制器的磁盘)：OS在逻辑格式化时检测坏块，并在FAT表中进行标记，避免使用(坏块对OS不透明)
            2. 现代的复杂磁盘：**控制器**内部维护一份坏块列表。该列表在低级格式化时初始化，并在使用过程中动态更新。低级格式化时预留对OS透明的**备用扇区**，当发现坏块时，控制器自动将其映射到备用扇区，从而实现逻辑替换，避免坏块使用(扇区备用机制)
3. 磁盘的地址结构
    1. 磁盘地址=(柱面号，盘面号，扇区号)，磁盘块号最终就转化为这个三元组
    2. 盘面号在中间，而不是柱面号在中间：切换盘面的成本低于切换柱面

4. 一次磁盘读/写操作的时间=寻道时间+旋转延迟时间+数据传输时间
    1. 寻道时间占主导地位(通常最长)，且直接受磁盘调度算法影响
    2. 旋转延迟时间和数据传输时间与磁盘转速成反比，这个由硬件决定，OS难以优化

5. 磁盘调度算法：主要目标是**减少磁盘的平均寻道时间**
    1. 算法总览
        ![[Pasted image 20260716093705.png]]
    2. 先来先服务(FCFS)：按进程请求访问磁盘的先后顺序进行调度，最简单
        ![[Pasted image 20260716085638.png]]
    3. 最短寻道时间优先(SSTF)：每次选择距离当前磁头位置最近的请求进行调度，以使单次寻道时间最短，但无法保证平均寻道时间最小(贪心，局部最优)
        ![[Pasted image 20260716090110.png]]
    4. 扫描算法(电梯算法)(SCAN)：引入了磁头移动方向约束，**磁头仅在到达最外侧磁道后才转向内侧移动，到达最内侧磁道后才转向外侧移动**
        1. 需要预先知道此时磁头的移动方向
        2. 利好靠近两侧的磁道请求：刚向右处理过184，没过多久往左回时又可以处理184；而中间区域的响应延迟较大
        ![[Pasted image 20260716090920.png]]
    5. 循环扫描算法(C-SCAN)：磁头仅沿单一方向移动并提供服务，**返回时快速移动到起始端且不处理任何请求**
        1. 需要预先知道此时磁头的移动方向
        2. 将回扫过程转化为非服务性的快速跳转，以循环方式均匀处理所有请求，从而有效缓解了SCAN算法的不公平性
        3. 跳回起始端的时候也是跳到实际的最旁边，而不是请求队列的最旁边哈
        ![[Pasted image 20260716093102.png]]
    6. LOOK、CLOOK调度算法：分别是对SCAN和C-SCAN算法的改进版本。改进内容：**磁头只需要移动到当前方向上最远的请求位置即可返回，而不用到端点**
        ![[Pasted image 20260716093431.png]]
        ![[Pasted image 20260716093505.png]]
        ![[Pasted image 20260716093603.png]]
    7. NStepSCAN、FSCAN：解决磁壁黏着现象
        ![[Pasted image 20260716093855.png]]
        ![[Pasted image 20260716155547.png]]
6. 减少旋转延迟时间的方法：扇区交替编号，盘面错位命名
    1. 基本原理：当磁头读取一个扇区后，**系统需要一定时间处理数据**，才能开始读取下一个扇区，此时所有磁头都无法工作。而盘面是不停旋转的，这就意味着处理期间可能错过预期扇区，导致需要多等一圈
        ![[Pasted image 20260802105411.png]]
        ![[Pasted image 20260716095422.png]]
    1. 扇区交替编号：同一盘面上，逻辑上相邻的扇区在物理布局上保持适当间隔
        1. 假设访问顺序是012，则连续编号会错过扇区，交替编号可以保证不错过扇区
        ![[Pasted image 20260716095812.png]]
        ![[Pasted image 20260716095543.png]]
    2. 盘面错位命名：不同盘面上，各扇区交错排布(上下同位置扇区号不同)
        1. 同一柱面上的块通常按盘面顺序连续存放：0号(0-7)、1号(0-7)......
        2. 假设依次访问0号盘面的7号扇区、1号盘面的0号扇区。则采用普通命名会错过扇区，而错位命名不会
        ![[Pasted image 20260716101214.png]]

9. 固态硬盘(SSD)：常用作外存
    1. 知识总览
        ![[Pasted image 20260716103121.png]]
    2. SSD是一种**基于闪存技术**的存储设备，属于电可擦除ROM，即EEPROM
        1. 一个SSD由一个或多个闪存芯片以及闪存翻译层组成
        2. 闪存芯片替代了传统磁盘中的机械驱动器，每个闪存芯片包含多个块，每个块包含多个页
        3. 闪存翻译层负责将CPU发出的逻辑请求转化为对物理闪存的读写控制信号，相当于磁盘控制器(负责翻译逻辑块号，找到对应页)
        ![[Pasted image 20260716103025.png]]
    3. 读写操作(支持随机访问)以页为单位进行，擦除操作以块为单位进行
        1. 只有整块被擦除后，才能向其中的页写入新数据
        2. 每个块的擦写次数有限，经若干次重复写入后，该块会因磨损而失效
        ![[Pasted image 20260716103512.png]]
    4. 磨损均衡：延长SSD的寿命
        1. SSD的主要缺点在于**闪存的擦写寿命有限**(易磨损)。如果磨损不均衡，很可能导致SSD快速报废
        2. 磨损均衡技术
            1. 静态磨损算法通常比动态磨损算法表现更优秀
            ![[Pasted image 20260716104009.png]]
    5. 固态硬盘 VS 机械硬盘
        1. 固态硬盘随机读/写性能明显高于机械硬盘
        2. 机械硬盘因需寻道,反而在**连续存取**上相对占优
        3. 文件系统需要为两者**确定盘块大小**
        ![[Pasted image 20260716103750.png]]
