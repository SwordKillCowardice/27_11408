2. I/O设备的基本概念和分类
    1. IO设备管理的核心是：通过软硬件协作，屏蔽不同设备的物理差异，使应用程序能以统一方式使用各类设备
        ![[Pasted image 20260712103719.png]]
    2. IO设备的定义
        1. IO设备是指能够向计算机输入数据或接收其输出数据的外部设备，属于硬件
            ![[Pasted image 20260711111216.png]]
        2. IO设备通常由"设备本身"(机械部件)和设备控制器(电子部件)组成。"设备本身"是执行具体输入输出操作的物理装置(如磁盘的磁头)，设备控制器则是连接到系统总线上的专用电路，负责将OS发出的抽象命令转换为设备可识别的电信号，协调主机和设备间的数据传输
        3. UNIX系统将外部设备抽象为一种特殊的文件，用户可以使用与文件操作相同的方式对外部设备进行操作

3. I/O接口(I/O控制器、设备控制器)(掌握)
    1. I/O接口是CPU与设备之间的桥梁，用于实现计算机与设备之间的数据交换。它接收CPU发出的命令，控制设备工作(CPU通过控制I/O接口来控制设备的机械部件)

    3. I/O接口的组成(三部分)
        1. 一个I/O接口可以连接一个或多个设备，通过通信总线进行连接
        2. 控制/状态/数据寄存器可能有多组(每组寄存器对应一个具体的设备)，这些寄存器需要有相应的地址。使用I/O指令(属于专用指令)访问寄存器
        3. 控制/状态寄存器可复用：先使用控制寄存器发命令字(控制字)，再使用状态寄存器得设备状态。二者使用时间恰好错开，所以可以复用

5. **I/O软件层次结构**
    1. 四层示意图
        1. 后三层属于操作系统内核(大部分IO软件位于OS内核)
        2. 最下面的硬件就是IO设备，不属于软件层次
        ![[Pasted image 20260711164803.png]]
        ![[Pasted image 20260712100317.png]]
    2. 用户层软件：**实现与用户的交互接口**。用户可以直接调用**用户层提供的IO库函数**对设备进行操作(如printf函数)，用户层软件再通过对应的系统调用获取OS服务(如printf对应的write系统调用)
    3. 设备独立性软件(设备无关性软件)
        1. 设备独立性：应用程序在使用IO设备时，无需依赖具体的物理设备，而是使用逻辑设备名进行IO操作
        2. 系统引入逻辑设备与物理设备以实现设备独立性：**应用程序使用逻辑设备名请求某类设备**，系统负责将逻辑设备名映射为实际的物理设备名
            ![[Pasted image 20260712093830.png]]
        3. 设备独立性软件位于设备驱动程序之上，是内核IO子系统的最高层。其核心职责是**实现各类设备的公共操作，并为上层提供统一、抽象的IO接口**。具体功能如下
            1. 向用户层/文件系统提供统一的调用接口(如read系统调用)
            2. 设备保护(禁止用户直接访问硬件)
            3. 实现逻辑设备名到物理设备名的映射，根据设备类型选择调用相应的驱动程序(使用**逻辑设备表**实现)
                ![[Pasted image 20260712094018.png]]
                ![[Pasted image 20260712094047.png]]
                ![[Pasted image 20260712094138.png]]
            ![[Pasted image 20260713121310.png]]
    4. 设备驱动程序(负责"翻译"，控制设备控制器，管理IO设备)
        1. 不同设备的内部硬件特性不同，而设备驱动程序与硬件直接相关，故**每类设备都要配置一个专用的驱动程序**，设备驱动程序需实现对应OS的接口要求
            ![[Pasted image 20260712103416.png]]

6. 应用程序I/O接口
    1. 定义：OS为统一管理各类IO设备而设计的一套软件架构与编程规范
    2. 按设备分类：OS将物理设备抽象为三种通用类型：字符设备、块设备和网络设备，并为每类设备提供标准的接口
        1. 字符设备(流设备)：数据的存取与传输以字符为单位
            1. 传输速率低、不可寻址、通常采用中断驱动方式
            2. 大部分字符设备属于独占设备，因此接口还需提供打开和关闭操作，以实现互斥共享
        2. 块设备：数据的存取与传输以数据块为单位
            1. 传输速率高、可寻址、采用DMA方式
            2. 接口隐藏了磁盘的物理二维结构，向上层暴露$0-(n-1)$的线性空间
        3. 网络设备：用于网络通信
        ![[Pasted image 20260712102010.png]]
    3. 按执行模式分类：阻塞IO与非阻塞IO
        1. 阻塞IO(多数OS采用)：进程发起IO请求后，若所请求的数据未就绪，则该进程立即被阻塞
            ![[Pasted image 20260712103028.png]]
        2. 非阻塞IO：进程发起IO请求后，内核不阻塞该进程，而使系统调用立即返回。若数据尚未就绪，则调用返回一个错误状态，进程可据此继续执行其他任务，并在时机合适时重新执行该操作
            ![[Pasted image 20260712103147.png]]
