# 1.知识点
1. 磁盘高速缓存
    1. 磁盘高速缓存是指**利用内存中的存储空间**暂存从磁盘读取的盘块数据，这些数据是磁盘内容的副本，访问高速缓存中的数据比直接读写磁盘更高效
    2. 两种实现方法
        1. 在内存中开辟固定大小的专用缓存区
        2. 将系统空闲内存作为动态缓冲池，供请求分页系统和磁盘IO子系统共享使用

    3. 单缓冲
        1. 当用户进程请求IO时，OS在内存中为其分配**一个缓冲区**，其大小通常为一个数据块。缓冲区空时，才能写数据；缓冲区满时，才能取数据
        2. 工作图示+处理每块数据所需时间
            1. 工作区的大小默认与缓冲区大小相同
            2. T和C并行，只用计两者中更大的那个

            ![[Pasted image 20260713130118.png]]
    4. 双缓冲(缓冲对换)
        1. 工作图示+处理每块数据所需时间
            1. T可以与C+M并行
            2. 相比单缓冲，IO速度更快，设备利用率更高
            ![[Pasted image 20260713134212.png]]
            ![[Pasted image 20260713134503.png]]
        2. 实现全双工通信，每台机器需**分别设置发送缓冲区和接收缓冲区**，单缓冲区无法实现
            ![[Pasted image 20260713134822.png]]
    5. 循环缓冲区(多缓冲机制)
        1. 将多个大小相等的缓冲区组织成环，每个缓冲区包含指向下一个缓冲区的链接指针(循环队列)
        2. 系统维护in指针和out指针：in指向下一个待写入的空缓冲区，out指向下一个待读取的满缓冲区。输入进程负责推进in指针，计算进程负责推进out指针，沿着链接方向循环移动，从而实现输入和计算的并行
        ![[Pasted image 20260713140113.png]]
        ![[Pasted image 20260713140050.png]]
    6. 缓冲池(多缓冲)(在主存中)
        1. 缓冲池是一种包含管理数据结构和操作函数的软件机制，用于**统一管理多个支持多进程共享使用的缓冲区**
        2. 缓冲区的组织方式(三个队列)
            1. 空缓冲队列：链接空缓冲区
            2. 输入队列：链接装满输入数据的缓冲区
            3. 输出队列：链接装满输出数据的缓冲区
            ![[Pasted image 20260713140803.png]]
        3. 缓冲区的使用方式(四种角色)
            1. 收容输入缓冲区：暂存输入数据
            2. 提取输入缓冲区：读取输入数据
            3. 收容输出缓冲区：暂存输出数据
            4. 提取输出缓冲区：读取输出数据

    2. 设备分配应考虑的因素：设备的固有属性、设备分配算法、设备分配的安全性

    2. 由于并不是使用真正脱离主机控制的外围机，所以叫"假"脱机
