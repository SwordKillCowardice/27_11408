3. 操作系统的定义和功能
    1. 定义：系统资源的管理者、向上层提供易用的服务、系统软件
        ![[Pasted image 20260330124933.png]]
    2. 功能：管理系统资源、向上层提供易用的服务、扩展硬件机器
        1. 管理系统资源：文件管理、存储器管理、处理器管理、设备管理(依次对应)
            ![[Pasted image 20260330130749.png]]
        2. 向上层提供方便易用的服务(封装)
            1. *GUI*(图形化用户接口)：图形界面
            2. 联机(交互式)命令接口：就是命令行。用户说一句，系统做一句
            3. 脱机(批处理)命令接口：用户说一堆，系统做一堆
            4. 程序接口：由系统调用组成，是给程序员和软件(应用程序)提供的。普通用户不能直接使用，只能通过程序代码间接使用。
                1. **应用程序通过程序接口请求操作系统服务，并访问系统资源**
                2. 库函数本身并非操作系统的接口。有的库函数封装了系统调用，因此程序员可以通过调用这类库函数来触发系统调用；有的库函数则不涉及任何系统调用(普通库函数)
                3. 系统调用需要陷入内核态执行，而普通库函数通常在用户态执行
        3. 实现对硬件机器的扩展：实现比裸机更强的功能
            ![[Pasted image 20260330131706.png]]
4. 操作系统的四个特征
    1. 并发：计算机系统中多个程序宏观上同时运行(区别于并行)
        ![[Pasted image 20260330133314.png]]
    2. 共享：系统中的资源可供多个进程共同使用。
        1. 互斥共享的资源称为临界资源
        2. 同时共享在微观上既可能交替，也可能不交替(打游戏时放音乐，对扬声器资源的使用)
        ![[Pasted image 20260330133607.png]]
    3. 虚拟：把一个物理实体变为若干个逻辑上的对应物(用户感受到的比实际大)
        ![[Pasted image 20260330134049.png]]
        ![[Pasted image 20260330134114.png]]
    4. 异步：多个程序并发执行，但各自的执行是走走停停的，以不可预知的速度推进
        ![[Pasted image 20260330134349.png]]
    5. 关系
        1. 并发和共享互为存在条件，也是最基本的特性：并发才需要共享、共享才能够并发
            ![[Pasted image 20260330133755.png]]
        2. 没有并发，就没必要实现虚拟
        3. 没有并发，就不可能导致异步
5. 习题
    1. 存储器管理专指对主存的管理。外存虽然也是操作系统管理的资源，但主要由文件管理和设备管理负责
    2. 文件管理负责文件的存储组织、访问方式等内容，但不涉及文件内容的具体语义
        ![[Pasted image 20260330142717.png]]
    3. 系统调用的目的是**请求系统服务**，服务包括获取资源、完成某个操作等
    4. 系统命令：操作系统提供给用户的命令行操作工具，用于执行某些系统功能或控制程序运行
# 1.2 操作系统发展历程
1. 重点关注绿框内的部分，绿框外的只用了解。绿框内的需要关注和理解各类操作系统主要想解决的问题，各自的优缺点
    ![[Pasted image 20260330152601.png]]
2. 手工操作阶段
    1. 不能并发
    2. 从纸带机输入输出(速度远慢于计算速度)，导致处理器大量时间空闲，资源利用率低下
    ![[Pasted image 20260330150905.png]]
3. 单道批处理系统
    1. 不能并发
    2. 引入监督程序
    3. 从磁带输入输出(较手工操作速度有所提升)，资源利用率依然低下
    ![[Pasted image 20260330151140.png]]
    ![[Pasted image 20260330151646.png]]
4. 多道批处理系统
    1. 能并发(操作系统诞生，往后都能并发)，资源利用率大幅提升
    2. 不能进行人机交互
    ![[Pasted image 20260330152018.png]]
5. 分时操作系统
    1. 主要用于交互式作业，可以人机交互(时间片轮转服务)
    2. 追求快速响应用户，响应时间=时间片大小X用户数($T=QN$)
    3. 采用优先级+非抢占式调度算法可以改善整体响应时间
    4. 不能优先处理紧急任务
    ![[Pasted image 20260330152147.png]]
6. 实时操作系统：
    1. 可以响应紧急任务。分为硬实时系统和软实时系统
    2. 强调及时处理数据并做出响应
    3. 主要特点包括：确定性(响应时间可预测)、高可靠性、强时效性
    ![[Pasted image 20260330152325.png]]
