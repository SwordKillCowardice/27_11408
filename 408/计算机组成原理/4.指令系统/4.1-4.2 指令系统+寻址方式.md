# 1.知识点
1. 指令集体系结构(ISA)
    1. 机器指令(指令)是指示计算机执行某种操作的命令，是计算机运行的最小功能单位
    2. 一台计算机所有指令的集合构成它的指令系统，也称指令集。指令集是指令集体系结构(ISA)的核心部分，而**ISA完整定义了软硬件之间的接口**
        ![[Pasted image 20260813093642.png]]
    3. 一台计算机只能执行自己指令系统中的指令，而不能执行其他系统的指令
    4. **机器语言和汇编语言程序员必须熟悉ISA**，熟悉ISA和硬件特性可以开发更优的程序
    ![[Pasted image 20260807111709.png]]
2. 指令的基本格式与分类
    1. 指令的基本格式：操作码(指明指令的功能)+地址码(被操作对象的地址)
        ![[Pasted image 20260807112337.png]]
        ![[Pasted image 20260813093911.png]]
    2. 指令的分类
        1. 按地址码的个数
            1. 零地址指令：无地址码，但**可能需要隐含的操作数**。堆栈计算机可联想后缀表达式运算过程
                ![[Pasted image 20260807112755.png]]
            2. 一地址指令：1个地址码
                ![[Pasted image 20260807113138.png]]
            3. 二、三地址指令
                1. 二地址指令中，$A_1$的地址也是结果地址
                ![[Pasted image 20260807135621.png]]
            4. 四地址指令：会修改PC的值
                ![[Pasted image 20260807135714.png]]
            5. 若地址码部分总长度不变，则地址码个数越多，寻址能力越差(每个地址码的位数少)
        2. 按指令长度是否相等
            1. 指令字长 VS 机器字长 VS 存储字长
                ![[Pasted image 20260807140107.png]]
            2. 定长指令取指和译码简单，有利于流水线实现
            ![[Pasted image 20260807140140.png]]
        3. 按操作码长度是否相等
            1. 字长为32位或更长的系统中，常采用定长操作码
            ![[Pasted image 20260807140454.png]]
            ![[Pasted image 20260807142334.png]]
        4. 按指令功能分类
            1. 区分调用指令与转移指令：前者会返回，后者不返回
            2. CPU控制指令仅允许内核代码使用
            3. 顺序控制指令也叫程序控制类指令
            ![[Pasted image 20260807140809.png]]
3. 扩展操作码指令格式
    1. 使用定长指令字+可变长操作码，**操作码长度随地址码减少而增加**
    2. 在有限的指令字长内，支持更丰富的指令种类，但控制器的设计更复杂        
    3. **设计准则及举例**
        1. **短操作码不能成为长操作码的前缀**、各指令的操作码不能重复
        2. 使用频率高的指令应分配较短的操作码，以减少指令译码和分析的时间
        3. 注意理解$m\times 2^n$种状态
        ![[Pasted image 20260807141958.png]]
        ![[Pasted image 20260807142523.png]]
4. 指令寻址：确定下一条将要执行的指令地址，有顺序寻址和跳跃寻址两种方式
    1. 寻址方式：即确定指令或操作数有效地址的方法，分为指令寻址和数据寻址
        ![[Pasted image 20260813093745.png]]
    2. 顺序寻址：程序计数器自增，自动形成下一条指令地址。**(PC)=PC+"1"**
        1. 采用定长指令字结构时：PC自增的大小是一条指令所占用的地址单元数(按字节编址时，即字节数)
            ![[Pasted image 20260808095009.png]]
        2. 采用变长指令字结构时：先取出指令的一个字，根据op判断该指令所占用的地址单元数n。取完整条指令后，PC自增n
            ![[Pasted image 20260808095306.png]]
    3. 跳跃寻址：通过转移类指令实现，**转移目标地址由指令给出**。取出转移指令后，PC先自增；执行转移指令且确定要转移后，再修改PC的值为目标地址
        1. 数的比较通过减法运算+标志判别实现
        ![[Pasted image 20260808100748.png]]
        ![[Pasted image 20260808111129.png]]
5. 数据寻址：确定本条指令操作数的地址，有10种方式
    1. 地址码字段 = 寻址特征 + 形式地址A
        1. 寻址特征字段的位数决定了可支持的寻址方式种类
        2. 操作数的真实地址称为有效地址EA
        3. (A)表示地址A处存放的内容，A可以是寄存器编号或内存地址
        ![[Pasted image 20260808101403.png]]
        ![[Pasted image 20260808101828.png]]
    2. 寻址方式总结
        1. **寄存器寻址的地址段位数最短**
        2. **隐含寻址**不需要地址码字段，故**可以简化地址结构**
        ![[Pasted image 20260808112050.png]]
    3. 隐含寻址：操作数地址隐含在特定寄存器中
        ![[Pasted image 20260808103953.png]]
    4. 立即(数)寻址：A即操作数，**执行速度最快**
        ![[Pasted image 20260808104223.png]]
    5. 直接寻址：EA = A
        ![[Pasted image 20260808102726.png]]
    6. 间接寻址：EA = (A)
        ![[Pasted image 20260808103159.png]]
    7. 寄存器寻址：EA = $R_i$
        ![[Pasted image 20260808103519.png]]
    8. 寄存器间接寻址：EA = $(R_i)$
        ![[Pasted image 20260808103754.png]]
    9. 偏移寻址(3种)：以某个地址为起点，形式地址视为偏移量
        1. 基址寻址：EA = (BR)+A
            1. 既可以使用专门的基址寄存器，也可以由程序员指定一个通用寄存器作为基址寄存器。**无论哪种方式，基址寄存器的内容只能由OS修改，在程序执行过程中，其内容保持不变**
                ![[Pasted image 20260808105645.png]]
            ![[Pasted image 20260808105211.png]]
            ![[Pasted image 20260808105830.png]]
        2. 变址寻址：EA = (IX)+A
            ![[Pasted image 20260808110351.png]]
            ![[Pasted image 20260808164141.png]]
            ![[Pasted image 20260808110434.png]]
        3. 相对寻址：EA = (PC)+A
            1. PC就是一个寄存器，跟其他寄存器(BR、IX)一样，本质上是一块能存二进制数的硬件单元。它的特殊之处在于"存的内容有固定的含义(下一条指令地址)"，以及"它的更新方式主要靠硬件自动完成(自增)或由转移类指令强制改写，而不是靠普通数据处理指令去操作它"
            ![[Pasted image 20260808110833.png]]
    10. 堆栈寻址：操作数隐含在堆栈中，通过更新堆栈指针来修改取数/存数位置
        1. 硬堆栈：由高速寄存器构成，成本高，容量小
        2. 软堆栈：从主存中划定一段区域，更实惠
        ![[Pasted image 20260808111551.png]]
