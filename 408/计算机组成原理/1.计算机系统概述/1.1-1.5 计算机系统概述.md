# 1.知识点
1. 计算机发展历程(了解即可，大纲已删除)
    1. 计算机硬件的发展：记忆四代计算机的逻辑元件就行
        1. 四代计算机
            1. 世界上第一台电子数字计算机叫ENIAC
            2. 电子数字计算机：使用机器语言编程、主存容量小、计算机体积大、运算速度低
            3. 晶体管计算机(时代)：出现高级语言及其编译程序、计算机体积减小、运算速度提升、出现操作系统雏形
            4. 中小规模集成电路：高级语言迅速普及、出现分时操作系统、计算机并未普及
            5. 超大规模集成电路：微处理器诞生、个人计算机(PC)萌芽
            ![[Pasted image 20260717100504.png]]
        2. 计算机元件的发展
            1. 摩尔定律：在价格不变的前提下，集成电路上可以容纳的晶体管数量约每18个月翻一倍，使性能显著提升。这一定律揭示了信息技术的快速发展
            2. 半导体存储器的发展：存储器容量不断上升，已进入TB级别
            3. 微处理器的发展：机器字长(字长)变大。字长即CPU通用寄存器的宽度，它决定了单次整数运算可以处理的数据位数，以及可直接寻址的内存空间大小
    2. 计算机软件的发展：编程语言和操作系统软件蓬勃发展，并带动应用软件发展
    3. 目前的发展趋势：两极分化。小的更小，大的更大

2. 计算机系统的组成
    1. 计算机系统=硬件(有形的物理装置，如主机)+软件(在硬件上运行的程序及其相关的数据和文档)
        1. 计算机性能的好坏取决于软硬件功能的总和
        2. 计算机系统设计必须**合理划分软硬件的功能边界**。对于使用频繁且硬件实现成本较低的功能，宜用硬件实现，以显著提升整体效率
    2. 计算机硬件
        1. 两种计算机结构
            1. 冯诺依曼机的结构：存储程序+五大部件+以运算器为中心
                1. 主要特点
                    1. **存储程序思想**：虽然命名为存储程序，但实际是指**程序和数据**均以二进制形式预先存入主存储器(内存)中
                    2. 指令和数据地位等价
                    3. **以运算器为中心**：IO设备与存储器间数据传送通过运算器进行
                    ![[Pasted image 20260717143404.png]]
                2. 结构图示
                    1. 输入设备：将信息转化为二进制的0/1
                    2. 控制器：解析指令，协调各设备运行
                    3. **以运算器为中心**：IO设备与存储器之间无数据线
                    4. 软硬件逻辑等效：同一个功能既可以用硬件实现，也可以用软件实现。硬件成本高，速度快，软件反之
                    ![[Pasted image 20260717143454.png]]
            2. 现代计算机的结构：基于冯诺依曼机，但以存储器为中心
                1. 运算器、控制器和各类寄存器(如MAR、MDR)高度集成到一块芯片中，称为CPU
                2. 主机=CPU+主存

        3. 计算机的功能部件(基于现代计算机结构)
            1. 计算机的功能部件包含：CPU、存储器、IO设备以及**用于协调这些部件协同工作的总线**
            2. 中央处理器(CPU)：负责指令执行。按**数据通路**和**控制单元**进行组织
                1. 数据通路：是执行实际运算的硬件通路，其核心是算术逻辑单元(ALU)和通用寄存器组。数据通路还包含多路选择器等组件，用于在各个部件之间高速传送数据
                    1. ALU负责完成算术和逻辑运算
                    2. 通用寄存器组负责为ALU提供操作数并暂存运算结果，可以实现高速数据访问
                2. 控制单元：负责协调整个CPU的工作。取指、译码、生成控制信号，以指挥数据通路中各部件，从而确保指令有序、高效地执行
            3. 存储器：按访问特性分为内存和外存
                1. 内存=主存+高速缓存(题目不特别说明时，**"内存"= 主存**)
                2. 主存是核心的工作存储器，用于存放待执行的程序和数据
                3. 外存包括两类：可与主存交换数据的磁盘、固态硬盘等；用于长期备份数据的海量存储设备(如磁带、光盘)
            4. IO设备：即外部设备(外设)，由物理功能部件和设备控制器组成
                1. 物理功能部件负责实际的输入输出操作
                2. 设备控制器负责与主机通信并控制物理部件工作
                3. 外设通过设备控制器连接到主机上，各种设备控制器统称为IO控制器/IO接口。如显卡(显示控制器)、网卡(网络控制器)
            5. 总线：在各个部件之间传输信息的公共通路，CPU、主存和IO接口通过总线互连
            6. 硬件图示+数据流向说明

    3. 计算机软件
        1. 软件按功能可分为系统软件和应用软件
            1. 应用软件：用户为解决特定应用领域问题而开发的程序
            2. 系统软件：管理硬件资源，并向上层应用程序提供基础服务
            ![[Pasted image 20260717100042.png]]
        2. 软件和硬件的逻辑功能等价性
            1. 定义：同一个功能，既可用硬件实现(性能高，成本高)，也可用软件实现(性能低，成本低)。从用户视角看，二者在逻辑功能上是等价的
            2. 软/硬件逻辑功能等价性是计算机系统设计的重要依据，需要合理划分软/硬件的功能边界

3. 计算机系统层次结构
    1. 采用抽象思想+多级层次结构：每层对自己的功能实现进行抽象，向上提供简洁的接口，向下依赖更底层的功能实现。下层实现对上层往往是透明的
        ![[Pasted image 20260718221049.png]]
    2. 问题驱动视角下的层次图
        1. 算法与编程：算法即解决问题的步骤。确定算法后，程序员用编程语言实现该算法
            1. 编程语言：可分为高级语言和低级语言。高级语言独立于计算机底层硬件结构，是主流软件开发语言；低级语言则紧密依赖机器结构，特指机器语言及汇编语言
                ![[Pasted image 20260718111202.png]]
            2. 翻译程序：属于系统软件，将一种编程语言转化为另一种语言。主要包括编译程序、解释程序和汇编程序
                1. 编译器(编译程序)：把高级语言源程序**一次性全部翻译**成汇编语言程序或机器语言程序。**源程序不变时，无需重复编译**
                2. 汇编器(汇编程序)：把汇编语言程序翻译成机器语言程序
                3. 解释器(解释程序)：**逐条**读取源程序中的语句，**边翻译边执行**，不生成完整的目标程序文件
                4. 汇编程序 VS 汇编语言程序
                    ![[Pasted image 20260718104303.png]]
                5. 编译程序 VS 解释程序
                    ![[Pasted image 20260718104558.png]]
                ![[Pasted image 20260718103427.png]]
        2. 操作系统：操作系统通过对计算机硬件的抽象，构造出一台虚拟机，为软件(如上层的翻译程序)提供运行环境
        3. 指令集体系结构(ISA)：ISA是计算机软硬件之间的**关键接口**(界面)，完整地定义了软件可直接使用的硬件功能(**能做什么**)。主要包括：指令格式、操作类型、寻址方式，以及可访问的寄存器等硬件资源。ISA是软件可见部分
        4. 微体系结构(微架构)：是处理器内部的硬件组织方式，用于实现ISA定义的功能(**怎么做**)。其核心设计包括数据通路组织、控制单元实现、流水线级数等
        5. 相同的ISA可对应多种不同的微架构
        ![[Pasted image 20260718110558.png]]
    3. 用户角色视角下的层次图
        1. 最终用户：直接使用应用程序完成特定任务的人员，无需了解底层技术细节。处于最上层
        2. 系统管理员：负责配置、管理和维护计算机系统，确保其稳定高效运行的人员。主要职责包括：安装软硬件、管理用户账户、数据备份与升级等。工作在操作系统层面
        3. 应用程序员：使用高级语言开发应用软件的人员。工作在高级语言层面
        4. 系统程序员：设计并开发操作系统、编译器和数据库管理系统等核心系统软件的人员。工作在机器语言层面，直接面向ISA
        5. 同一用户可能在不同场景下承担多种角色
        6. 下层机器的结构特性对上层用户通常是透明的

4. 计算机系统的工作原理
    1. 从源程序到可执行文件
        1. C程序需要先转化为一系列机器指令，并按特定格式封装成可执行目标文件，最终以二进制形式存储于磁盘，之后才能调入内存执行
        ![[Pasted image 20260718135024.png]]
    2. "存储程序"工作方式
        1. 程序执行前，将其指令和数据加载到内存中。一旦启动后，计算机自动逐条取出指令并执行
        2. 程序执行前，先将第一条指令的地址存入PC，之后根据PC内容去主存储器取指令
        3. 系统根据指令类型更新PC

        4. 根据新的PC内容取出下一条指令

5. 计算机的性能指标
    1. 主存储器的总容量
        ![[Pasted image 20260718170337.png]]
    2. 数据通路带宽：数据总线一次所能并行传送信息的位数。各硬件部件通过数据总线传输数据，带宽大小影响传输次数，进而影响性能
    3. 吞吐量和响应时间
        ![[Pasted image 20260718162841.png]]
    4. **主频和CPU时钟周期**
        1. CPU时钟周期：机器内部主时钟脉冲的宽度，是CPU工作的**最小时间单位**。完成指令拆分成的每个动作至少需要一个时钟周期
            ![[Pasted image 20260718170806.png]]
            ![[Pasted image 20260718163115.png]]
        2. 主频(CPU时钟频率)：机器内部主时钟的频率，即**时钟周期的倒数**，是**每秒包含的时钟周期数**，单位是赫兹(hz)。对于同一个型号的计算机，主频越高，执行指令的每个步骤所需时间越短，运算速度越快
    5. **CPI**、IPC、**IPS**、MIPS
        1. CPI：执行一条指令所需的时钟周期数(时钟的个数)
            1. 对特定程序或机器而言，指的就是平均CPI
            2. 不同的指令，其CPI不同；相同的指令在不同时刻，CPI也可能不同
            ![[Pasted image 20260718163637.png]]
        2. IPC：CPI的倒数，每个时钟周期能完成多少条指令
        3. IPS：每秒执行多少条指令。IPS=主频/平均CPI
        4. MIPS：每秒执行多少百万条指令。描述CPU执行指令的频率
            ![[Pasted image 20260718164916.png]]
    6. **CPU执行时间**：运行一个程序所花费的时间。总时钟周期数\*时钟周期
        ![[Pasted image 20260718164116.png]]
    7. FLOPS：每秒执行的浮点运算次数
        ![[Pasted image 20260718165534.png]]
    8. **关于单位换算的说明**
        ![[Pasted image 20260718165603.png]]
    9. 基准程序(跑分软件)(动态测试)：一组专门用于性能评测的典型程序，旨在模拟真实应用场景下的负载，从而较为准确地反映系统在实际使用中的运行效率
        ![[Pasted image 20260718170000.png]]
        ![[Pasted image 20260718221225.png]]
    10. 说法判别补充
        1. 说法一：计算可知，虽然A的主频更高，但A**每秒能执行的指令条数**比B少
        2. 说法二：在第一问的前提下添加平均CPI相同。尽管A每秒能执行的指令条数比B多，但对于**同一个乘法计算**A所需的指令条数也比B多，故不一定更快
        3. 说法三：基准程序的测试往往是偏向某些特定指令的，即使更快也只能说明机器擅长这类指令，不能得出性能更好
