2. 基本运算部件(加法器+ALU实现)
    1. 基本概念
        1. 运算器由算术逻辑单元(ALU)、移位器、状态寄存器(PSW)和通用寄存器组等构成
        2. 运算器的核心部件是ALU，ALU的核心部件是加法器
    2. 全加器(FA)：实现1位相加
        ![[Pasted image 20260722164354.png]]
    3. n位串行进位加法器(行波进位加法器)：将n个全加器级联，以实现两个nbit数相加
        1. **进位信号逐级传递**，每一级的进位输出直接作为下一级的进位输入
        2. 由于位数固定，结果实际是模$2^n$的加法(**溢出部分被丢弃**)
        3. 总运算延迟主要由**进位信号从最低位传到最高位的时间决定**：位数越多，进位链越长，延迟越大。**缩短进位传递路径**是提升其性能的关键
        ![[Pasted image 20260722182925.png]]
        ![[Pasted image 20260722183651.png]]
    4. n位并行进位加法器(先行进位)：几乎可以**同时生成所有进位信号**，运算速度比串行加法器更快(知道这一点就够了)

3. 定点数的移位运算
    1. 对于任意二进制整数：左移一位，若不溢出，相当于乘以2；右移一位，若忽略舍去的末位尾数，则相当于除以2
        ![[Pasted image 20260722202101.png]]
        ![[Pasted image 20260722202138.png]]
    2. 逻辑移位：左移时，高位移出，低位补0；右移时，低位移出，高位补0
        1. 常用于处理无符号整数
        2. 左移时，若高位的1移出，则发生溢出
        3. 右移时，若低位的1移出，则丢失精度

        1. 常用于处理带符号整数
        2. 左移时，若左移前后的符号位不同，则发生溢出
        3. 右移时，若低位的1移出，则丢失精度

4. 定点数的加减运算及电路
    1. 原码的加减运算(了解)：需将符号位和数值位分开处理，逻辑较复杂
        1. 加法：**同号求和，异号求差**。符号相同，则保持符号位不变，将数值位相加。若数值位相加时**最高位产生进位**，则**溢出**；符号不同，则用绝对值较大者减去绝对值较小者，结果的符号位与绝对值大者相同，不会溢出
        2. 减法：将减数的符号取反，转换为等价的加法进行计算

        2. 溢出判断
            1. 溢出场景及原理
                1. 仅在**同号相加**(异号相减)时才可能发生**溢出**
                2. 溢出分为上溢和下溢：上溢回到负数，下溢回到正数。模运算机制导致了这种现象的发生，把数轴拉成一个环看就行
                ![[Pasted image 20260723103559.png]]
            2. 溢出判断方法(三种)：记住表达式
                1. 采用单符号位且发生溢出时：若符号位进位为0，则正溢出，否则负溢出
                2. 双符号位具有单符号位的全部优点，且更易于检查加减运算中的溢出问题
                3. 采用双符号位时，仅在ALU中为双符号位：**参与运算时，才进行复制**
                4. 采用双符号位时，**左符号位**始终**代表预期结果的符号**，右符号位仅用于辅助判别溢出。若左右符号位相同，则结果正确；**若左右符号位不同，则发生溢出**。由于异号相加不可能溢出，溢出只发生在同号相加的情况下，因此左符为0时正溢出(正+正)，左符为1时负溢出(负+负)
                ![[Pasted image 20260723104626.png]]
                ![[Pasted image 20260723104836.png]]

9. 有符号数的除法运算原理：硬件结构与无符号数的除法基本相同
    1. 被除数的扩展用符号扩展
    2. 上商：如果R的首位与Y的首位异号，则R+Y写入R，否则R-Y写入R。新R符号与老R相同，则商1，否则商0。商0需要恢复余数
    3. 结束：如果被除数和除数异号，得到的商需要取补
    4. 触发特殊情况时，不需要进行后续n轮，直接走异常或得结果
    5. 商溢出也属于特殊情况：对于n比特除法，硬件会检查被除数和除数是否正好满足溢出条件，溢出则不执行后续轮次
