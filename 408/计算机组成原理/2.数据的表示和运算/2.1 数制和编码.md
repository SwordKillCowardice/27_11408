# 1.知识点
1. 进位计数制及其相互转换
    1. 进位计数制：十进制、二进制、八进制、十六进制
        1. 基数：每个数位所能使用的不同数码的个数。比如十进制的基数是10，对应数码为0-9，计数时**遇10进1**
        2. 位权：每个数位的权重值。小数点前从$r^0$开始，往左递增；小数点后从$r^{-1}$开始，往后递减
        3. 数值计算：每一位的数码 X 该位位权，再求和(按权展开相加)
        ![[Pasted image 20260720132602.png]]
        4. 后缀O表示八进制数、十进制的后缀D通常省略
        ![[Pasted image 20260720133956.png]]
    2. 计算机**采用二进制**对信息进行编码的原因

    3. 不同进制数之间的相互转换
        1. 任意进制转十进制
            ![[Pasted image 20260720134352.png]]
        2. 二进制、八进制、十六进制互相转换
            1. 二进制转八进制：三位一组求数码，整数部分左补0，小数部分右补0
            2. 二进制转十六进制：四位一组求数码，整数部分左补0，小数部分右补0
            3. 八进制转二进制：一数码变三位二进制数，整数去左0，小数去右0
            4. 十六进制转二进制：一数码变四位二进制数，整数去左0，小数去右0
            5. 八进制转十六进制：先转二进制，再从二进制转目标
            ![[Pasted image 20260720134916.png]]
        3. 十进制转任意进制：逆用按权展开相加法
            1. **注意**：并非所有十进制小数都能用有限位二进制小数精确表示，但是有限位二进制小数则可以精确转化为十进制小数
            ![[Pasted image 20260720135646.png]]
            2. 对于整数部分：因为每个数码$K_i \in [0, r-1]$，$K_i$除以$r$留下的余数就是$K_i$. 根据按权展开式，最低位的$K_0$除以$r$之后首先成为余数，把除后的商作为新的被除数，则次低位的$K_1$下一轮成为新的余数
            3. 对于小数部分：最高位的$K_{-1}$乘$r$之后首先出现在整数部分，其他位则构成剩下的小数部分，重复乘法过程并取整数部分，就能得到所有位
            ![[Pasted image 20260720135727.png]]

    2. 无符号数的表示
        1. 通常只有无符号整数，没有无符号小数，故**无符号数就是无符号整数**
        2. 所有二进制位均用于表示数值，无符号位。**数值隐含为非负整数**
        3. 相同字长下，**无符号数能表示的最大值大于有符号整数**
        4. 常用于地址运算、指针等不涉及负数的场景

3. C语言中的整数类型及类型转换
    1. 整数类型
        1. 所有有符号整型均以**补码形式**存储，而无符号整型则按无符号数存储
        ![[Pasted image 20260722085710.png]]
    2. 类型转换
        1. C语言支持强制类型转换：`TYPE b=(TYPE)a`. 把a强制转换为TYPE类型，然后赋值给b
        2. 转换过程中，若涉及字长变化，则可能发生**位截断**和**位扩展**
            1. 位截断：长类型转短类型，**系统直接丢弃高位**，仅保留低位。**此类转换不会引起异常或错误**，但是会导致语义变化(转换之后的值与预期值不同)
            2. 位扩展：短类型转长类型，**系统填充高位**。**源数据为有符号数，则做符号扩展；源数据为无符号数，则零扩展**
                ![[Pasted image 20260722090645.png]]
                ![[Pasted image 20260722112601.png]]
                ![[Pasted image 20260722092442.png]]
        3. **同字长**整数类型相互转换：**二进制位保持不变，仅改变对这些位的解释方式**
