# 1.知识点
1. 存储器的层次化结构
    1. 金字塔结构
        1. 现代计算机普遍采用**多级存储器**结构，以缓解存储系统在**容量、速度与成本**之间的矛盾
        2. 从上至下，CPU访问频率下降
        3. 寄存器在CPU中，因此速度最快
        4. U盘也属于外存
        ![[Pasted image 20260728103505.png]]
    2. 三级存储结构及数据交换分析
        1. 把金字塔结构最下面两层统称为辅存，得到三级存储结构
        2. Cache-主存层和主存-辅存层是**关键层级**：前者的数据交换速度接近Cache，容量和单位成本却接近主存，其数据调度由**硬件**自动完成，对所有牛马透明；后者则速度接近主存，容成接近辅存，其数据调度由**硬件与OS**协同完成，仅对应用程序员透明
        3. Cache和主存可以直接与CPU交换信息，辅存则需先经过主存中转
        4. **上层存储器作为邻接下层的高速缓存**(上层内容是下层内容的子集)：当CPU访问数据时，按照Cache-主存-辅存的顺序逐级查找。若目标数据不在上层，则从下层逐级调入(在Cache没找到，而主存找到，则把数据调入Cache，然后重新访问Cache拿数据)。这一设计基于程序局部性原理

2. 存储器的分类
    1. 按层次分类
        ![[Pasted image 20260728110528.png]]
    2. 按存储元件(介质)分类
        1. 半导体存储器：使用半导体器件，利用电荷或者电压状态存储信息。如主存(DRAM)、Cache(SRAM)
        2. 磁表面存储器：使用磁性材料。如磁盘(机械硬盘)、磁带
        3. 光存储器：使用光介质。如光盘
    3. 按存取方式
        1. 随机存取存储器(RAM)：支持随机访问。读写任意存储单元的时间都相同，与存储单元所在的物理位置无关。半导体存储器属于此类(主存、Cache)
        2. 顺序存取存储器(SAM)：支持顺序访问。读写存储单元的时间与其所在位置有关，如磁带
        3. 直接存取存储器(DAM)：兼具随机访问和顺序访问的特点，比RAM慢，比SAM快。先直接定位目标区域，再按顺序读取数据，如磁盘
        4. 相联存储器(内容寻址存储器)(CAM)：按内容进行存取(指定内容，返回地址)。查找速度快(**根据存储内容进行并行匹配查找**)，与存储位置无关，但成本高、容量小，主要用于快表(TLB)和路由表
        5. 顺序存取存储器和直接存取存储器都属于串行访问存储器，即存取时间与存储单元位置有关的存储器
        6. 除了相联存储器，其他三种存储器都是按地址进行存取的(给目标地址，返回对应数据)
    4. 按信息的可更改性
        1. 可读可写存储器：可读也可写，通常采用随机存取。如RAM(内存、Cache)和磁盘
        2. 只读存储器(ROM)：支持随机存取。其中的信息在正常工作时只能读取，通常不可修改。部分类型支持特定条件下的重写。如BIOS通常在ROM中
    5. 按信息的可保持性
        1. 破坏性读出：DRAM
        2. 非破坏性读出：SRAM、磁盘、光盘
        ![[Pasted image 20260728131019.png]]
3. 存储器的主要性能指标
    1. 存取时间：完成一次读写操作所需的平均时间。读出时间是指从主存接收到有效地址到数据有效输出的时间；写入时间是指从主存接收到有效地址到数据成功写入指定单元的时间
    2. 存储周期：存储器进行连续两次独立的读/写操作所需的最小时间间隔，通常大于存取时间，因为每次读写操作之后，存储器需要恢复内部状态(Tm=Ta+Tr)
        ![[Pasted image 20260728131850.png]]
    3. 存储器带宽(数据传输率)：存储器每秒能够传输的最大数据量
    4. 存储容量：存储字数 X 存储字长
    5. 单位成本：总成本$\div$总容量
4. 主存储器(MM)的组成
    1. 核心部件是存储矩阵(存储体、存储阵列)：由大量用于存储0/1的记忆单元(存储元)组成，每个记忆单元是一种具有两种稳态、能表示0/1的器件
    2. 为访问存储体中的信息，需要进行编址，编址的单位是存储单元。存储单元，是指**具有相同地址的一组**记忆单元，一个存储单元对应一个地址。现代计算机**按照字节编址**，即一个存储单元(地址)对应个比特
    3. MAR：存储地址寄存器。CPU读写主存时，把目标地址放这，然后通过地址线送到主存的地址寄存器，再由地址译码器选中对应的存储单元。**MAR的位数等于地址线位数**，决定了主存的最大可寻址范围(地址从0开始)
    4. MDR：存储数据寄存器。读写内存时，要写/读到的数据放这里，然后通过数据线与存储单元交互。**MDR的位数等于数据线宽度**，决定了每次可并行存取的bit数
    ![[Pasted image 20260728132515.png]]
5. 半导体随机存取存储器(RAM)
    1. 随机存取存储器(RAM)分为**静态RAM**(SRAM)和**动态RAM**(DRAM)，二者都是**易失性存储器**。主存采用DRAM，Cache采用SRAM
    2. DRAM VS SRAM(高频考点)
        1. **核心区别**：存储元不同。DRAM用栅极电容，而SRAM用双稳态触发器
        2. SRAM的静态特性：非破坏性读出，无需再生。由于无需再生，所以存取速度更快
        3. DRAM使用电容，电容放电代表读出1，放电后信息被破坏，所以需要再生。**由于需要再生，所以存取速度较慢**。同时，由于电荷会因漏电逐渐丢失，所以需要**定时刷新以维持数据**
        4. SRAM使用双稳态触发器，体积更大，控制更复杂。因而芯片的集成度低(单位体积内的存储元数量少)，功耗大(发热量大)，单个存储元制造成本也更高
        5. SRAM地址线本身就比较少，所以同时送地址就行
        6. 传统DRAM与CPU采用异步方式交换数据
        7. 现在的主存通常使用同步DRAM(SDRAM)：与CPU采用同步方式交换数据，显著减少CPU等待时间，以提升系统性能
        ![[Pasted image 20260729094756.png]]
    3. 存储芯片的组成
        1. 驱动器：保证译码器输出的控制信号稳定有效(起放大作用)
        2. 双译码法(采用行列地址)：如果直接采用一维$n$位，则译码器接$2^{n}$根输出线；采用二维两个$\frac{n}{2}$位，则两个译码器各接${2}^{\frac{n}{2}}$，合计$2^{\frac{n}{2}+1}$根线
        3. 每根线都会对应一个金属引脚
        4. m X n的存储芯片：m是存储单元个数，n是存储字长

        1. DRAM存储芯片的基本原理

                2. 假设字长为4B，即每行4个地址单元。再假设存储字数为256，则总容量为1KB，对应1024个地址单元，地址10位，10根地址线

        2. 刷新机制：注意是**按行刷新**
            1. 刷新：每隔一定的时间向栅极电容补充一次电荷(充电)
            2. 芯片内部集成一个刷新计数器，可自动产生刷新所需的行地址
            3. 刷新周期：对特定行完成一次刷新后，到下一次对该行刷新的时间间隔
            4. 刷新周期为$2ms$：即$2ms$内要把所有行都刷新一遍，对应4000个读写周期内要抽出128个周期进行刷新

7. 多模块(多体)存储器
    1. 多模块存储器是一种**空间并行**技术，通过**多个结构完全相同的存储模块并行**工作来提高存储器的吞吐率：CPU的速率远高于存储器，而存储器每次存取完都需要一定的恢复时间。使用多模块，则在一个存储模块恢复时，CPU可以从另一个模块存取，从而降低等待时间，提高吞吐率
        ![[Pasted image 20260729133628.png]]
    2. 连续编址(高位交叉编址)的多模块存储器
        1. 高位地址为存储模块号，低位地址为模块内地址
        2. 根据体号确定存储模块，再把体内地址送到存储模块对应的译码器进行翻译
        3. **访问连续地址时**，总是**先访问同一个模块的连续单元**，直到该模块访问结束才访问下一个模块，本质SAM。**不能并行访问各个模块，访问一次后干等恢复，所以无优化效果**
        ![[Pasted image 20260729105508.png]]
        ![[Pasted image 20260729105531.png]]
        ![[Pasted image 20260729110202.png]]
    3. 交叉编址(低位交叉编址)的多模块存储器(多体交叉存储器)
        1. **低位地址为存储模块号，高位地址为模块内地址**。通过地址对模块总数取余，即可得到模块号(利用取余取出低位的模块号位)
        2. 支持模块间并行，优化效果明显

    4. 多体交叉存储器的两种启动方式
        1. 轮流启动：**数据总线位数等于每个模块一次读写的位数**，即每次读写只需要读一个模块。此时轮流启动各模块进行存取
            1. 连续**存取时间**的计算：要计入恢复时间，即按完成每个存取周期来算：所以是$mr+T-r = T+(m-1)r$. 其中$mr$为连续读取$m$个模块所需的时间，$T-r$为最后一个模块的恢复时间，其他模块的恢复时间已隐含在并行中
            2. 总线(传输)周期即存取时间
            3. 模块数$m>=\frac{T}{r}$

8. 主存储器与CPU的连接
    1. 连接原理
        1. 主存储器通过**数据总线、地址总线和控制总线**与CPU相连
        2. 数据总线的位数与其工作频率共同决定数据传输速率，其乘积正比于理论带宽
        3. 地址总线的位数决定了CPU可寻址的最大内存空间
        4. 控制线与存储器类型有关：SRAM包含片选和读写控制线、ROM仅需片选线、DRAM一般不设独立片选线，其芯片选择通过行列地址或外部译码实现
        5. 主存中往往包含多块存储芯片
        ![[Pasted image 20260731153545.png]]
    2. 主存容量的扩展：字数少字扩展，字长小位扩展
        1. 位扩展：增加存储字的长度，适用于CPU数据总线宽度大于单个芯片数据位宽的情况。通过并联多个芯片，使位宽匹配
            1. $A_0-A_{15}$为地址位，$D_0-D_7$为数据位。其中$0$下标为低位
            2. 各芯片的地址线、片选线(图中简化画成全1)和读写控制线并联；数据线各自连接到数据总线的不同位。所有芯片同时工作，选中同一个地址的位，构成一个完整字
            ![[Pasted image 20260731154334.png]]
            ![[Pasted image 20260731154346.png]]
        2. 字扩展：增加存储单元的数量(字数)，从而扩大地址空间，适用于地址总线位数多于芯片地址线位数的情况
            1. 各芯片的地址线连接至系统地址总线的低位，数据线和读写控制线并联至系统总线，系统地址总线的高位负责控制选片，各个芯片分时工作
                ![[Pasted image 20260731160656.png]]
            2. 线选法：地址总线的高位用于控制选片，任意时刻高位1个1，其余0，从而选中为1的那个芯片。问题：任意时刻只能有一个1，导致00、11等高位地址无法使用，**造成整个地址空间不连续**
                ![[Pasted image 20260731155304.png]]
            3. **译码器片选法**(主流)：地址总线的高位组合后送入译码器翻译，然后控制选中对应片，**地址空间连续**。带圈代表输出低电平或输入低电平有效
                ![[Pasted image 20260731155756.png]]
                ![[Pasted image 20260731160008.png]]
                1. 特殊情况：高位地址的中间位不参与译码，此时中间位$A_{14}$的取值不影响选片。**但是，地址空间遭到了扩大，这种方式只在做题看见**
                ![[Pasted image 20260731160434.png]]
        3. 字位同时扩展法：先进行位扩展，得到满足字长需求的芯片组。再将芯片组视为整体进行字扩展，从而选中特定的组
            1. 系统地址总线低位连接各组内部芯片的地址引脚，高位经译码器生成各组的片选信号
