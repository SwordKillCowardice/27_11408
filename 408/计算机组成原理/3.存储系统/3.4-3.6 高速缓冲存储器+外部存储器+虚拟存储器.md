# 1.知识点
1. Cache的定义与相关原理
    1. Cache由SRAM组成，通常**集成在CPU内部**，具有比主存更快的访问速度。使用Cache可以缓解CPU和主存速度不匹配的问题，显著提高存储系统的整体效率
    2. Cache机制对程序员透明，**完全由硬件实现**
    3. 程序访问的局部性原理(Cache设计的依据)
        1. 时间局部性：同一个数据或同一条指令大概率被多次访问，所以它所在的页也会被重复访问
        2. 空间局部性：连续存储的数据(如数组元素)通常共享一个页，对应的存储单元通常会被连续访问，导致这个页被多次访问
        3. Cache利用局部性原理，将程序当前活跃的部分数据暂存与高速的Cache中，使CPU的多数访存操作直接在Cache中完成，从而显著提高程序执行效率
        ![[Pasted image 20260701144011.png]]
        ![[Pasted image 20260629112314.png]]
    4. Cache的访问流程与性能分析
        1. Cache和主存都被划分为大小相等的块。Cache块也称Cache行，Cache中的块数远少于主存中的块数，**这里的行/块指的都是纯数据行/块**。**一个页的大小通常相当于多个块，不要把页和块混为一谈**
            ![[Pasted image 20260803095811.png]]
        2. **每次被访问的主存块，一定会被立即调入Cache**

            2. $t_m$称为缺失损失，即从主存调入一个块所需的时间

2. Cache和主存的映射方式：区分Cache和主存的数据块对应关系
    1. Cache每行设置一个**标记，记录其主存块编号**；设置一个**有效位，指示该行的数据是否有效**，主存块装入Cache后，其有效位设置为1
    2. 地址映射：将主存地址空间按照一定规则映射到Cache地址空间，即决定主存块如何装入Cache(限制主存块可以占据的Cache位置)
        ![[Pasted image 20260802160312.png]]
    3. 全相联映射：主存中的块可以装入**Cache中的任意位置**
        1. CPU访存时需与所有Cache行的标记进行比较
        2. 需要使用按内容查找的相联存储器
            ![[Pasted image 20260802153542.png]]
            ![[Pasted image 20260802153606.png]]

        ![[Pasted image 20260802152820.png]]
        ![[Pasted image 20260802153206.png]]
        ![[Pasted image 20260802153217.png]]
    4. 直接映射：主存中的块只能装入**Cache中的唯一位置**。若该位置已有内容，则发生**块冲突**，直接替换原有块(无需块置换算法)
        1. 实现简单，但灵活性差，有时Cache中有空闲空间，也无法使用。**块冲突概率最高，空间利用率最低**
        2. 主存块号的低$c$位即为对应的Cache行号，故标记只需要存块号的高$m-c$位
        ![[Pasted image 20260802154340.png]]
        ![[Pasted image 20260802154637.png]]
    5. 组相联映射：将Cache划分为Q个大小相等的组，主存中的块只能装入**对应组中的任一行**，即**组间直接映射，组内全相联映射**
        1. Q=1时就是全相联映射；Q=总行数时就是直接映射
        2. 每组r行时称为**r路组相联映射**。r越大，同组内位置越多，冲突概率越低，但所需的逻辑更复杂，成本更高
        3. 同直接映射，主存块号的低$log_2Q$位即为对应的Cache组号，故标记只需要存块号的高$m-log_2Q$位

4. Cache的一致性问题：CPU修改Cache中的内容后，如何维持Cache和主存数据的一致
    1. 写命中时(CPU要写的块已经在Cache中)
        1. 回写(写回)法：仅将数据写Cache，**不立即写主存，仅在该块被替换时才写回主存**
            1. 回写法是**唯一**需要使用**脏位**(修改位)的，脏位为1代表该Cache块修改过
            2. 替换时，脏位为1的块必须写回主存，而脏位为0的块不写
            3. **减少了主存访问次数**，提高了Cache效率，**但存在数据不一致的风险**(在脏块写回前，Cache和主存数据不一致)
            4. 速度快，更适合**访问密集型**的应用
        2. 全写法(直写法)：**数据同时写Cache和主存**，一般使用写缓冲减少开销
            1. 替换Cache块时直接覆盖，无需写回
            2. 数据同时写Cache和写缓冲(SRAM实现)，写缓冲异步地将数据写入主存
                1. 采用转发策略避免数据不一致
                2. 写操作高频时，写缓冲可能饱和甚至溢出
                ![[Pasted image 20260802184524.png]]
            3. 访存次数增加，速度慢，但能**保证数据一致性**，适合**安全性要求高**的应用
            ![[Pasted image 20260802184756.png]]
    2. 写未命中时(CPU要写的块不在Cache中)(凉面Π)
        1. 王道教材：**写分配法在主存写完再调回Cache**，这个与老观点不同；非写一致
            ![[Pasted image 20260802185638.png]]
        2. 老观点：两种组合方法
            1. 写分配法搭配回写法，分别应对命中与否两种情况
                ![[Pasted image 20260802185941.png]]

7. Cache的应用
