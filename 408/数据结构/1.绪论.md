# 1.1 数据结构的基本概念
1. 知识总览
    ![[Pasted image 20260309214350.png]]
2. 基本概念(了解)
    1. 数据是信息的载体
    2. 数据元素是数据的基本单位，数据项是构成数据元素的最小单位
        ![[Pasted image 20260309211242.png]]
    3. 数据对象是具有相同性质的数据元素的集合
    4. 数据类型：值的集合和定义在此集合上的一组操作
        ![[Pasted image 20260309220015.png]]
    5. 抽象数据类型(ADT)：抽象数据组织(逻辑结构)+操作(运算)，等价于定义了一个逻辑结构
    6. 关键字：可以唯一区分数据元素
3. **数据结构**(重点)
    1. 即彼此之间**具有特定关系**的数据元素的集合。结构指元素之间的关系
        ![[Pasted image 20260309215054.png]]
    2. **数据结构三要素**
        1. 逻辑结构：数据元素之间的逻辑关系
            ![[Pasted image 20260309215257.png]]
            1. 集合：各个元素同属一个集合，别无其他关系
            2. 线性：一对一
            3. 树形：一对多
            4. 图状：多对多
        2. 物理结构(存储结构)：用计算机具体实现。包括数据元素的表示及其相互关系的表示
            ![[Pasted image 20260309215510.png]]
            1. 顺序：逻辑上相邻物理上也相邻
            2. 链式：逻辑上相邻物理上可以不相邻
            3. 索引：建立索引表，每个表项称为索引项(关键字+地址)
                ![[Pasted image 20260309215738.png]]
            4. 散列：哈希表
        3. 数据的运算/基本操作(定义+实现)：运算的定义针对的是逻辑结构，指出运算的功能；而实现针对存储结构，指出运算的具体步骤
        4. 确定逻辑结构和运算就是定义了一个数据结构，而确定存储结构用于实现数据结构
        5. 理解：顺序存储需要分配大块的连续空间，而非顺序不用(第二点)
            ![[Pasted image 20260309215828.png]]
4. 习题
    1. 逻辑结构仅描述元素之间的逻辑关系，而不关心具体存储(数据的逻辑结构独立于其存储结构)
    2. 有序表指的是关键字有序的线性表，是一种逻辑结构
    3. 在存储数据时，不仅要存储各数据元素的值，还要存储数据元素之间的关系

2. 算法
    1. 对特定问题求解步骤的一种描述，是指令的有限序列，每个指令表示一个或多个操作。描述时可以用自然语言、伪代码、代码
    2. 可行性：算法可以用代码实现并运行
    3. 算法有零个或多个输入，有一个或多个输出
3. **时间复杂度**$T(n)$(时间效率)(重点)
    1. 是一种事先估计法
        ![[Pasted image 20260315114435.png]]
    2. 计算
        1. 可以忽略低阶项和系数
        2. 关注循环体内某一行就行，嵌套循环看最内层。循环体外顺序执行的代码可以忽略
        3. 遇到递归程序时，求出每层递归的大致执行时间，再累加/直接乘以递归层数
        4. 算法的执行时间和输入的数据有关，故有最好、最坏和平均三种情况。一般只考虑最坏和平均情况
            ![[Pasted image 20260315114750.png]]
4. **空间复杂度**$S(n)$(存储需求)(重点)
    1. 程序运行时的内存需求：指令+常数+变量(与*n*无关的)+输入数据+辅助空间。只需要考虑辅助空间大小(与问题规模*n*相关的变量)
    2. 算法所需的空间复杂度为常数级时，称算法原地工作
    3. 递归程序的空间复杂度分析
        1. 每层所需空间大小为常数：每层的空间大小x递归深度
            ![[Pasted image 20260315115020.png]]
        2. 每层所需空间大小非常数：逐层分析并求和
            ![[Pasted image 20260315115111.png]]
