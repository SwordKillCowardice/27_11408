# 实践与认识
1. 实践的本质和基本特征
    1. 实践的本质
        1. 错误观点
            1. 中国古代哲学：认为实践是人与人之间的道德伦理行为，忽视了人与自然
            2. 康德：局限于道德活动
            3. 黑格尔：认为实践是精神活动
            4. 费尔巴哈：认为实践是人的生理行为，比如吃喝拉撒
        2. 正确观点
            1. 感性的(能动)：受人的头脑和意愿指导
            2. 对象性：主体指向客体，并改造客体
            ![[Pasted image 20260813102328.png]]
    2. 基本特征
        1. 客观实在性(直接现实性)：实践具有**将脑中物变成现实物**的功能，强调做了之后才变成现实
        2. 自觉能动性：实践受头脑指挥，体现主体的目的、意愿和创造性，强调做之前要想好
        3. 社会历史性：不同历史阶段，实践不一样
2. 实践的基本结构和形式
    1. 基本结构：主体、客体、中介
        1. 主体：只能是人
            1. 自然能力是身体，精神能力是思维(知识性因素就是学的东西，非知识性因素就是信念这些)
            ![[Pasted image 20260813104123.png]]
        2. 客体：实践活动的对象
            ![[Pasted image 20260813104403.png]]
        3. 中介：工具+使用工具的方法
            ![[Pasted image 20260813104524.png]]
        4. 主客体的关系
            1. 实践关系：改造它，是最根本的关系
            2. 认识关系：认识它，先实践才认识。实践和认识具有同构性(主客体一致)
            3. 价值关系：客体对主体有用
            ![[Pasted image 20260813104826.png]]
        5. 基本结构的变化：主体客体化、客体主体化
            1. 主体客体化：我根据目的改造客体，让客体能够为我所用(客体变)
            2. 客体主体化：我吃了药，病好了(主体变)
    2. 基本形式
        1. 物质生产实践(劳动)，**最基本的**
        2. 社会政治实践(处理人和人的关系)
        3. 科学文化实践(探索未知领域)
        4. 虚拟实践(在网上当串子)不是基本形式，而是从前三种基本形式派生出来的
        ![[Pasted image 20260813123216.png]]
3. 实践对认识的决定作用
    1. 实践的地位
        1. 实践是认识的基础，在认识活动中起决定性作用
        2. 实践的观点是马克思主义首要和基本的观点
        3. 实践的观点是认识论的第一和基本观点
        4. 人与世界的关系：认识世界(认识)+改造世界(实践)
        5. 认识有赖于实践，反之是错的
        ![[Pasted image 20260813101802.png]]
    2. 决定作用的四个方面
        1. 实践是认识的来源(决定性)。但不是唯一来源(其它来源都是影响因素)。比如间接经验(报纸、道听途说)、生理因素(天赋)
        2. 实践是认识发展的动力
        3. 实践是认识的目的。有需求才会去认识
        4. 实践是检验认识真理性的唯一标准。获得认识是在此岸，去彼岸(实践)才能检验，实践和认识隔一条河
4. 认识的本质
    1. 错误观点
        1. 二元论：认为物质和意识都是本源，导致不可知，即不可认识。最终归于不彻底的唯心主义
        2. 唯心主义(彻底的)：从思想感觉到物，先验论
        3. 旧唯物主义(除马克思)：直观机械的反映(镜子)
    2. 辩证唯物主义(马哲)：认识是能动反映
        1. 反映是人类认识的基本规定性
        2. 能动可以创造
        3. 能动和反映没有先后关系
        ![[Pasted image 20260813131246.png]]
    3. 能动反映论的优点
        ![[Pasted image 20260813131448.png]]
5. 认识的过程(两次飞跃)
    1. 从实践到认识(一飞)(感性认识到理性认识)
        1. 感性认识：感官能感受到，肤浅
            1. 感觉(事物的一个方面，苦辣酸甜、光刺眼)、知觉(众多感觉组成的对一个事物的看法，吃起来甜，摸起来硬)、表象(形成知觉之后，得到的对事物的印象)
            2. 先有感觉，感觉综合成知觉，得到知觉之后就有表象
            ![[Pasted image 20260813132051.png]]
        2. 理性认识：更深刻
            1. 概念：思维的基本单位，比如西瓜
            2. 判断：有了概念之后，就可以判断
            3. 推理：有了判断，才能推理
            ![[Pasted image 20260813132339.png]]
        3. 二者辩证统一
            1. 不分对错，而是深浅关系
            ![[Pasted image 20260813132605.png]]
            ![[Pasted image 20260813132616.png]]
        4. 实现飞跃的条件
            1. 调查是获得感性材料，研究是理性分析
            2. 夸大理性认识：教条主义、伪理论
            3. 夸大感性认识：经验主义、经验论
            ![[Pasted image 20260813132921.png]]
    2. 从认识到实践(二飞)(理性认识到感性认识)：是认识过程中更为重要的一次飞跃
6. 认识过程中的影响因素
    1. 非理性因素又叫感性因素
    2. 理性因素和感性因素都影响认识的形成，而感性认识和理性认识都是已形成的意识(都受两种因素影响)
    ![[Pasted image 20260813133845.png]]
7. 认识的两大规律
    1. 反复性：两次飞跃重复循环。幸福的关键在于稳定的认识。如果你现在认可不婚，认可机器人伴侣，你也这样去做了，你这个想法几十年也不改变，你这些日子就能幸福
        ![[Pasted image 20260813142554.png]]
    2. 无限性：认识永无止境，螺旋上升

# 真理与价值
1. 认识的结果
2. 真理及其特性
    1. 真理是对客观事物及其规律的正确反映。认错了就是谬误
    2. 真理的特性
        1. 客观性：真理的内容是客观的(内容就是客观事物及其规律)、真理的标准是客观的(实践检验)
            1. 真理总体是客观的(笼统)，但是也有主观的部分(形式)。可以说真理是客观的，也可以说真理有主观的一面
            2. 承认客观性，就是坚持真理问题上的唯物主义
            3. 主观真理论(错误观点、唯心的)
                1. 但是可以说真理是有用的
                ![[Pasted image 20260813143542.png]]
        2. 一元性：对同一个事物的不同认识中只有一个是真理。一元性由客观性决定(衍生)，二者同存同灭
        3. 绝对性：确定性(是对的)+发展性(能认全)
            ![[Pasted image 20260813143842.png]]
        4. 相对性：待扩展+待深化
            ![[Pasted image 20260813143943.png]]
        5. 绝对性和相对性的关系
            1. 相互依存
            2. 相互包含：**相对包含绝对的颗粒**，反之错误
                ![[Pasted image 20260813144111.png]]
            3. 真理发展的规律
                1. **无数相对真理的总和构成绝对真理**
                ![[Pasted image 20260813144306.png]]
        6. 真理既有绝对性，又有相对性
            1. 至上性(无限性)：人有能力认识一切，所以真理具有绝对性
            2. 非至上性(有限性)：人目前还认识不了那么多，所有真理具有相对性
            3. 只讲绝对性，教条主义；只讲相对性，怀疑主义(诡辩论)
    3. 真理和谬误的关系
        1. 相互独立
        2. 相互依存、相互转化
            1. 同一范围内，真理和谬误绝对对立，不能转化
            2. 改变范围后，可以相互转化
            ![[Pasted image 20260813153110.png]]
3. 真理的检验标准
    1. 实践是检验真理的唯一标准，原因两点
        1. 真理的本性(主客观的相一致)
        2. 实践的特点
        3. 实践具有直接现实性，只有实践能把主客观联系起来
    2. 实践是检验真理的唯一标准，但不排斥逻辑证明的作用

4. 真理与价值(有用吗)的辩证统一
    1. 价值的基本特性
        1. 主体性：不同的人对事物的价值有不同看法，即主客体关系不同则价值变化
        2. 客观性：价值不以人的意志为转移
        3. 多维性：事物的价值对不同的人不同
        4. 社会历史性：不同时期同一个事物的价值不同
    2. 价值评价的特点及标准
        1. 人的两种认识
            1. 知识性认识：主体认识客体本身(这是一个苹果)
            2. 评价性认识：主体对主客体之间的关系进行认识(我喜欢苹果吗)
        2. 特点及标准
            1. 评价的对象是主客体关系
            2. 评价结果与评价主体直接相关
            3. 评价的正确与否依赖于自己的知识
            4. 评价也分对错(徐涛是字母圈的，666)
