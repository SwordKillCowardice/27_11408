# 哲学及其基本问题
1. 哲学的基本问题：思维(精神、意识)和存在(物质)的关系问题。分两个方面：
    1. 物质和意识何者具有第一性(先有谁)
        1. 唯物主义：认为物质具有第一性，即先有物质后有意识。按对物质定义分流派
            1. 古典(朴素)唯物主义：物质就是实物(水火土)
            2. 机械唯物主义：物质是原子等粒子构成的事物。机械唯物真包含于形而上学
            3. 辩证唯物主义(独属于马克思的唯物主义)：物质是一切客观存在。第一次把人类历史当物质来看，这种观点叫唯物史观(历史唯物主义)，即把历史当物质来研究得到的观点
                1. **马克思在哲学史上的两大贡献是创立唯物史观和辩证唯物主义**
                2. 马克思主义之前只有唯心史观，前两派的唯物主义(旧唯物主义)研究自然界时唯物，研究人类历史时唯心，因而也称半截子唯物
                3. 马唯物比前两派唯物范围更广，真包含关系
        2. 唯心主义：认为意识具有第一性，先有意识后有物质。按对意识(精神)的定义分流
            1. 主观唯心主义：世界的本原是本我的精神(我自己的心)
            2. 客观唯心主义：世界的本原是独立于人之外的精神(道、理学、上帝)
    2. 物质和意识是否具有同一性(人的意识能不能认识外部世界的物质，能则同一)
        1. 可知论：具有同一性。唯物主义和唯心主义都是可知论，唯物从物到感觉思想，唯心从思想感觉到物。二者认识的结果相同，仅认识路线不同
        2. 不可知论：不具有同一性。二元论者，尝试调和唯物和唯心，认为两者都有第一性。没有老大，无法做到统一，故不可知
2. 哲学的重要问题：世界是怎样存在的(在回答了基本问题后进一步探究)，根据观点不同分两派：
    1. 形而上学：世界是孤立的、片面的、静止的、无矛盾的
    2. 辩证法：世界是联系的、全面的、发展的、有矛盾的
3. 世界本源和世界存在方式两两组合
    1. 在马克思之前没有辩证唯物，只有其他三种组合

# 物质观
1. 物质范畴
    1. 恩格斯：物是世界上所有物的总和，物的概念是从总和中抽象出来的
        1. 物质：世界上所有物的总和
        2. 物质的概念(物质范畴)：从物质(总和)中抽象出来的东西(共性)
    2. 列宁：物质不依赖于人的意识而存在(客观实在性)，且能为人的意识所反映(可知论)。这种客观实在，是从自然存在和社会存在(人类历史)中抽象而出的共性
    3. 总之，**物质是可以被人感知的一切客观实在**
2. 物质和运动(变化)
    1. **运动是物质的存在方式**和根本属性，一切物质都是以运动着的状态存在的
    2. 物质和运动的关系是不可分割：运动是物质的运动(否认物质则陷入唯心主义），物质是运动着的物质(否认运动则陷入形而上学)
    3. **A和B不可分割**(两大关系之一)：A是B的A，B是A的B。A和B词性不一样，通常就是不可分割
3. 运动和静止
    1. 相对静止是物质运动在一定条件下的稳定状态，包含**空间的相对位置暂时不变**和**事物的根本性质暂时不变**两种状态
    2. 运动和静止**对立统一**：既相互区别，又相互联系。夸大静止叫形而上学，夸大运动叫诡辩论 
        ![[Pasted image 20260804202633.png]]
        ![[Pasted image 20260804202646.png]]
    3. A和B对立统一(辩证、辩证统一、矛盾关系)(两大关系之二)：A和B既相互区别，又相互联系。A和B词性一致时，大概为对立统一
4. 物质运动和时空
    1. 物质的存在方式是运动，而运动(着的物质)的存在方式是时空
    2. 时空的五大特点
        1. 客观性：不以人的意志为转移
        2. 有限性：具体事物的时空是有限的(人的一生，人能涉足的天地)
        3. 无限性：整个物质世界的时空是无限的(马认为宇宙是无限的)           
        4. 绝对性：时空绝对存在，每个人的1min长度相同，1cm相同
        5. 相对性：运动速度到达极限时，时空会发生变化。空间会扭曲，时间会缩短
    ![[Pasted image 20260804202855.png]]
5. 物质世界的二重化(分化)
    1. 物质世界二重分化的原因：人类的出现(**人类改造世界的实践活动**是导致世界分化和统一的关键)改变了世界的面貌，导致自然界中分化出人类社会、客观世界中分化出主观世界
    2. 二重分化的方面1：分为自然界与人类社会
        1. 人类社会是最高级的物质存在形态
        2. 自然界和人类社会不是截然分开的，而是交叉重叠，相互作用的
    3. 二重分化的方面2：分为客观世界和主观世界
        1. 主观世界(意识)从客观世界分化而出，具有**相对独立性**(有关联，但不是只能照搬)。举例：我看到了物质A，但我的脑子可以进行加工，导致我看到的东西B来自A，但和A不完全一样。物质A从我眼前拿走了，但是我脑子里还有印象，还记得关于A，也算
        2. 主观世界不是独立存在的，不能脱离客观世界而孤立存在，而是从属于客观世界
# 意识观、世界的物质统一性
1. 意识的起源
    1. 意识是自然界长期发展的产物，意识是人独有的
    2. 意识也是社会历史发展的产物
    3. 促进意识产生的因素有很多：其中劳动(属于实践)起**决定性**作用，语言起促进作用(重要影响)
    4. 用**决定性、根本、中心**修饰的才是真的重要，只用**重要修饰**代表有影响，没那么重要。考试会把重要拔高成决定性或者贬低成无影响，这两者都是错误的
    ![[Pasted image 20260805155235.png]]
2. 意识的本质
    1. 意识不是人脑，也不是人脑的分泌物(因为意识就是意识，意识不是特殊的物质，而后两者都是物质)
    2. 意识是我们对外部世界的**能动反映**。来自外部世界，但是我们进行了加工(这个加工就是**能动**)，与外部世界不完全相同。只看能动导致唯心、不可知论；只看反映导致旧唯物主义(直观反映、机械主义)
    3. 意识的内容是客观的：因为内容就是物质
    ![[Pasted image 20260805160728.png]]
3. 意识对物质的反作用(能动作用)
    1. 第一点：你可以决定你想认识(学)什么
    2. 第二点：会加工
    3. 第三点：意识影响你的行动，而你的行动会改造外部世界
    4. 第四点：意识影响心理健康
    ![[Pasted image 20260805161811.png]]
4. 物质和意识对立统一
    1. 不能说物质和意识互相代替，但是可以说相互转化，通过实践进行转化
    2. 转化：看到物质鸟，形成脑中鸟；根据脑中鸟，构想脑中飞机，创造物质飞机
    3. 考试判别准则：如果题干讲物质和意识的区别(比如画饼不能充饥)，就只能选区别的句子；如果讲联系(望梅可以止渴)，就只能选联系的句子
    ![[Pasted image 20260805162136.png]]
5. 主观能动性(意识具有)和客观规律性(物质具有)的辩证统一
    1. 只能动做不成事，只规律做不成有价值的事
    2. 先尊重规律，后发挥能动，才能做成有价值的事(成功的实践)。**如果题干强调其中一个更重要，你要顺着它选**
    3. 实际包括：客观实际(了解外部世界)和主观实际(了解自己)

    3. 人工智能没有感性的部分(情感、意念)、人工智能没有社会性(社会关系)
