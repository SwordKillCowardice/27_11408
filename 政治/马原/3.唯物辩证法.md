# 两大总特征
1. 世界如何存在：普遍联系和变化发展
2. 事物的普遍联系
    1. 四大特点(深入理解)
        1. 客观性：不以人的意志(光脑子里想)为转移。但是我们可以通过**实践**(行动)改变联系
        2. 普遍性：三句话
            1. 事物内部有联系
            2. 事物之间有联系
            3. 世界是一张联系网。每个事物都在网中，通过中介联系其他事物，也作为其他事物之间联系的中介
        3. 多样性：联系有很多形式
        4. 条件性
            ![[Pasted image 20260806200208.png]]
    2. 方法论：用系统观念看待事物，不要孤立地看问题
3. 事物的变化发展
    1. 发展的内涵：事物变化中**前进的**、上升的运动
        1. 运动=变化>发展：因为发展必须是往好的方向
        2. 发展并不是绝对的和无条件的，与运动不同
        3. 发展是永恒的：大方向向前，局部可能不变甚至倒退
    2. 发展的实质：新事物(合乎历史前进方向、具有远大前途)的产生和旧事物(丧失历史必然性、日趋灭亡)的灭亡
    3. 新事物必然战胜旧事物
        1. 新事物更新，适应新环境
        2. 新事物批判地继承了旧事物，优于旧事物：同一对新旧事物之间确实有先后关系，但不属于同一对的新旧事物之间没有必然先后关系
        3. 新事物符合人民的利益
        ![[Pasted image 20260806201742.png]]
    4. 方法论：要用过程观点看世界，动态地把握世界
4. **多选题解题思路**
    1. 先抓题干侧重点：有侧重点的话，**与题干侧重点相反的选项**即使表述正确也**不选**，即使和题干相关也不选(如题干侧重运动，则静止相关不选)
    2. 体会题干关键词：**与题干关键词并列**的**不能选**(如题干在讲经济发展，则民主政治建设不能选，但是伟大复兴可以选，因为伟大复兴包含这两个并列子维度)
    3. 超越上述两条规则的选项，只要和题干沾边(弱相关)，就可以选
# 三大规律
1. 三大规律在两大总特征的基础上，进一步分析世界的存在方式
2. **对立统一规律**(唯物辩证法第一规律) #论述题
    1. 对立统一规律是唯物辩证法的**实质和核心**，回答了**事物为什么会发展**的问题
        ![[Pasted image 20260807185859.png]]
    2. 对立统一(矛盾)规律下属的四大矛盾原理：每个都可能单独出论述题
        1. 矛盾的同一性和斗争性的关系原理
            1. 矛盾(对立统一)是什么：成对存在的事物构成一对矛盾，如美丑。矛盾是反映事物内部或事物之间对立统一关系的哲学范畴
            2. 矛盾的**基本属性**是**对立(斗争性)和统一(同一性)**
                1. 常用搭配：对立统一等价于斗争同一
                2. 一对矛盾**每时每刻既同一，又斗争**。而不是时而同一，时而斗争
                3. 相互依存：矛盾着的对立面不能单独存在
                4. 根据矛盾斗争激烈程度，可分为对抗性矛盾(很激烈)和非对抗性矛盾(相对缓和)。资本主义社会必将灭亡(社会中存在对抗性矛盾)
                ![[Pasted image 20260807191130.png]]
            3. 斗争性和同一性的关系：相互依存
                1. 寓于(不能换序)：同一性搭戏台，斗争性唱戏
                2. 斗争就是区别，区别是绝对的；而同一指关联，关联是有条件的
                ![[Pasted image 20260807191635.png]]
            4. 方法论：看事物要一分为二、物极必反+中庸不极端(矛盾的双方可以互相转化)
                ![[Pasted image 20260807192311.png]]
        2. 矛盾的同一性和斗争性事物发展中的作用
            1. 在事物的发展过程中，同一性和斗争性都起作用
            2. 同一性占主导地位时，事物表现为相辅相成；斗争性占主导地位时，事物表现为相反相成
            ![[Pasted image 20260807192645.png]]
            ![[Pasted image 20260807192802.png]]
        3. 矛盾的普遍性(共性)和特殊性(个性)
            1. 定义及其关系
                1. 任何一个事物既有共性，又有个性
                2. 共性寓于个性，个性包含共性
                ![[Pasted image 20260807193504.png]]
            2. 方法论
                1. 共性和个性，是矛盾的**精髓**
                2. 人的认识：由认识个别上升到认识一般，再由认识一般到认识个别的辩证发展过程
                3. 矛盾的共性和个性是马基原同各国实际相结合的哲学基础
                4. 具体问题要具体分析，而不能照搬共性，否则陷入教条主义
        4. 矛盾的不平衡发展原理
            1. 矛盾要分主次，矛盾的两个方面也要分主次
            2. 方法论：两点(主次矛盾都要看到)、重点(突出主要矛盾)
            ![[Pasted image 20260807194201.png]]
3. 量变质变规律(第二规律)：研究发展的过程
    1. 质(是什么)：一个事物区别于其他事物的内在规定性。认识质是认识和实践的起点和基础。只有认识质，才能区别事物
    2. 量：认识的深化和精确化。认识质相当于区别开政治老师和数学老师，而认识量相当于区别开不同的政治老师
        ![[Pasted image 20260808193734.png]]
    3. 度和关节点：度是区间，关节点是端点。超过关节点，则A事物变成了B事物
        ![[Pasted image 20260808193945.png]]
    4. 量变和质变对立统一
        ![[Pasted image 20260808194349.png]]
        1. 相互区别：量变连续不显著，质变中断根本性
        2. 相互联系：第三点是量变之中有质变，质变之中有量变
            ![[Pasted image 20260808194934.png]]
        3. 只看质变，激变论；只看量变，庸俗进化论
4. 否定之否定规律：探究发展的方向
    1. 肯定/否定因素：前者维持现存事物存在，后者促使现存事物灭亡。任何一个事物既有肯定因素，又有否定因素
    2. 辩证否定观
        1. 自我否定：是自己让自己灭亡(必然发生)，如基因控制人死亡。
        2. 扬弃：批判性地继承
        3. 形而上学认为外在力量消灭事物(偶然现象)，形而上学主张肯定一切/否定一切
        ![[Pasted image 20260808195610.png]]
    3. 否定之否定规律
        1. $A->B->A'->B'......$：事物在矛盾着的两者之间不断横跳，每次跳回都比上一次发展更好
        2. 种子->树->种子
        3. 只看螺旋不看上升，循环论；只看前进，直线论
